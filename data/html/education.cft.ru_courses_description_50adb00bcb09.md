# Учетное ядро. Настройка процентных схем и бухгалтерских проводок (бизнес-операций)

дистанционно

8

​Большинство финансовых операций банка сопровождаются формированием определенного
набора платежных документов. Для унификации процесса описания, автоматического
формирования и многоэтапной обработки такого набора документов в системе
«ЦФТ-Банк» существует справочник «Бизнес-операции».

Справочник
«Бизнес-операции» позволяет описать шаблоны проводок, соответствующих конкретным
финансовым операциям банка. Отражение логической взаимосвязи документов на
системном уровне реализуется посредством включения их в папку
платежей.

Ряд финансовых операций банка требует гибкой настройки схем
начисления процентов и выполнения самого процесса расчета. Для унификации
процесса описания и расчета процентов в системе «ЦФТ-Банк» существует приложение
«Схемы начисления процентов». Наличие в системе такого справочника
позволяет:

- унифицировать все параметры, используемые для настройки процентных схем
- унифицировать сам механизм расчета процентов посредством выполнения операции
  «Расчет процентов» на основании схем данного справочника

Исходными данными для
операции «Расчет процентов» является выписка по счету и период расчета.
Результатом расчета является сумма рассчитанных процентов. Кроме того, в
процессе расчета заполняется «Журнал начисленных процентов».

**Цели
курса**

Вы узнаете:

- Назначение бизнес-операций (БО) в системе
- Что такое дистрибутивные бизнес-операции, каковы особенности работы с
  ними
- Какие справочники используются при настройке бизнес-операций, каково
  назначение каждого из них
- Что такое схема проводок, каким образом она реализуются
- Что такое папка платежей
- Каким образом инициируется операция формирования
  папок платежей
- Связь между документами, сформированными одной БО
- Что представляет собой массив «Схема проводок»
- Основные принципы начисления процентов
- Механизм начисления процентов, для каких видов банковских операций он
  используется
- Особенности работы с календарями
- Каким образом осуществляется экспорт и импорт бизнес-операций со связанными
  данными
- Технологию настройки бизнес–операций в системе
- Последовательность действий при создании БО

Вы научитесь:

- Создавать бизнес-операции, требуемые в вашей работе
- Формировать документы комиссий по бизнес-операциям
- Просматривать результат выполнения бизнес–операций
- Выполнять настройку начисления процентов
- Выполнять начисление процентов по настроенным схемам
