# Проверка версии от 21.11.2026

Проверки выполнены на Python 3.12.14, PostgreSQL 16.2 и Node.js 24.22.3.

| Проверка | Результат |
| --- | --- |
| Авторизация на настоящей PostgreSQL | 7 тестов пройдено |
| Импорт SQLite → PostgreSQL | 2 теста пройдено |
| Python-бэкенд с PostgreSQL, тестовыми HTTP-ответами auth/RAG | 10 тестов пройдено |
| SSE и API фронта | 5 тестов пройдено |
| `npm run build` (TypeScript + Vite) | Успешно |
| Синтаксис Python | Успешно |
| YAML, пути Dockerfile, зависимости compose, LF в entrypoint | Проверено |
| Реальные HTTP-сервисы через прокси Vite | Успешно, RAG заменён временной заглушкой |

Всего 24 автоматизированных теста. В проверках PostgreSQL не заменялась на SQLite. Тесты используют отдельные временные схемы и удаляют их после выполнения.

HTTP-проверка запускала отдельные процессы auth и бэкенда, настоящий PostgreSQL и Vite. Она проверила регистрацию, cookie/CSRF, создание диалога, SSE с источниками, сохранение ответа, передачу истории следующему запросу, выход/вход, получение истории новым HTTP-клиентом без прежнего хранилища, независимость нового чата, разрыв сетевого SSE с сохранением частичного текста и удаление диалога.

Тесты миграции проверили неизменность исходной SQLite, сохранение хеша пароля, вход старым паролем, действующую старую сессию, счётчики попыток, повторный импорт и откат транзакции при конфликте.

Полный Docker-стек не запускался: Docker в среде проверки отсутствует. Загрузка моделей Ollama, реальный поиск Qdrant, индексация вашего датасета и качество ответов модели требуют проверки в вашем окружении. Исходный архив не содержал датасета, файлов моделей и реальной `auth.db`.

Графический браузер не удалось запустить из-за ограничений среды на Unix sockets. Визуальная проверка обновлённого интерфейса в этой версии не выполнена. Проверены сборка, клиентский SSE/API-код и сквозные HTTP-запросы; это не заменяет проверку кликов и отображения в браузере.

Команды запуска и переноса старых аккаунтов приведены в `README.md`.
