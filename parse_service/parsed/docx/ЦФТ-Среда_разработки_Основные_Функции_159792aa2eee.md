# ЦФТ-Среда разработки

Описание основных функциональных характеристик. Инструкция для разработчиков («первые шаги»).

АО «ЦФТ»

01/04/2025

### Введение

Система «ЦФТ-Среда разработки» (далее – «Система», «Среда разработки») предназначена для индивидуальной и коллективной разработки бизнес-приложений на трех архитектурных уровнях:

Структура хранения данных бизнес-приложения;

Поведение бизнес-приложения;

Пользовательский интерфейс бизнес-приложения.

При этом Система бесшовно интегрирует все эти уровни между собой и обеспечивает органичную интеграцию кода бизнес-приложений АО «ЦФТ» (далее – «ЦФТ») и кода локального бизнес-приложения, разработанного потребителями бизнес-приложений ЦФТ (далее – «клиенты»).

Ключевой возможностью является работа с исходными кодами бизнес-приложений в виде файлов на языке PL+. Файлы объединяются в индивидуальные компоненты (проекты), образующие бизнес-приложение. Среда разработки интегрируется с современными системами контроля версий, благодаря чему разработчики могут оперативно установить авторство изменений, группировать изменения по задачам, проектам, оперативно извлекать и развертывать предыдущие версии объектов и т.д.

Инструмент включает прекомпилятор исходного кода с языка PL+ на исходный язык java, а также содержит отладчик кода.

Свобода в выборе системы и стратегии управления исходным кодом позволяет выстраивать коллективный процесс с максимальным учетом особенностей продукта и команды разработки.

Среда разработки поддерживает практики CI (Continuous Integration — непрерывная интеграция) и DevOps (development & operations — активное взаимодействие и интеграция разработчиков и специалистов по ИТ обслуживанию, помогающие быстрее создавать и обновлять программные продукты и сервисы).

Среда разработки обновляется автоматически из настроенного репозитория её компонент.

Разработчики имеют возможность программирования в автономном режиме, за исключением выполнения операций, требующих сетевого подключения к базе данных.

Разработчик бизнес-приложений может сформировать внешний вид среды разработки под свои потребности – разместить окна на нескольких мониторах, выбрать цветовую гамму, то есть максимально персонализировать свое рабочее место, что значительно повышает комфорт разработки.

Инструментарий обеспечивает возможность проверки совместимости локальных решений клиента с новыми версиями бизнес-приложений ЦФТ на уровне API без участия ЦФТ и без необходимости развертывания бизнес-приложений в базе данных.

### Основные функции

Среда разработки является основным рабочим модулем разработчика и позволяет:

проектировать структуру/модель прикладных объектов (типов данных) достаточной сложности;

разворачивать спроектированные структуры/модель в системе хранения данных СУБД;

проектировать в дизайнере витрины/представления данных;

проектировать в дизайнере экранные формы методов, выполняемых на клиентском месте пользователя;

описывать алгоритмы обработки прикладных объектов на высокоуровневом языке PL+, поддерживающим объектную модель данных;

компилировать исходные коды на языке PL+ в исходный код для java среды исполнения;

автоматически добавлять в генерируемый код проверку назначенных пользователю прав;

назначать бизнес-пользователям предельно детализированные права на просмотр и обработку прикладных объектов.

### Создание унифицированных бизнес-приложений, независимых от баз данных

При соблюдении определённых правил разработки (ANSI SQL, отсутствие СУБД-специфичных возможностей) возможно создание унифицированных бизнес-приложений, поддерживающих различные СУБД (например, и СУБД Oracle, и СУБД PostgreSQL)

Обеспечивает бизнес-приложения средствами взаимодействия c БД линейки PostgreSQL.
