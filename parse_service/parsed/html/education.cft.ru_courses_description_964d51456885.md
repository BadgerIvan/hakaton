# Master Support

дистанционно

50

Курс направлен на базовую подготовку сотрудников подразделений технической поддержи и ИТ-сопровождения банков, которые используют ЦФТ-Банк в качестве core-banking системы и консультируют пользователей по вопросам, связанным с работой платформы (функционал, настройка, идентификация ошибок и т. д.). Преподаватели курса − практикующие эксперты ЦФТ.

## Цели курса

## Вы узнаете:

- основы банковского дела
- основы бухгалтерского учета и его автоматизации
- основные принципы сопровождения финтех-сервисов
- больше информации о платформе ЦФТ-Банк (Учетное ядро, кредиты, депозиты, отчетность)

Формат: дистанционные видео-курсы, тесты, онлайн встречи с преподавателями

Длительность: 7-8 недель (45-50 часов)
