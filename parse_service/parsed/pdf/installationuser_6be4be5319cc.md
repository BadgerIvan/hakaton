Исходный код хранится в git.
• ЦФТ-Среда разработки 2MCA DBI - для разработки приложения на базе Платформы 2 MCA
DBI. Исходный код хранится в git.

## Страница 20

Получение и установка лицензии
Получение лицензии
Для получения лицензии необходимо определить идентификатор инсталляции.
Для этого открыть окно Oкно › Параметры… › ЦФТ-Среда разработки › License, скопировать
значение поля [ ID инсталляции ].
Данный идентификатор будет использован далее для получения/обновления лицензии/ключа ЦФТ-
Среда разработки/ЦФТ-Среда разработки Basic/ЦФТ-Среда разработки/ЦФТ-Среда разработки
2MCA DBI, для этого необходимо сформировать запрос в Личном кабинете в разделе "Лицензии
ЦФТ-Среда разработки" (https://lk.cft.ru/lic_ide) либо обратиться к Менеджеру сопровождения вашего
Банка. После обработки запроса файл лицензии будет направлен Вам.
По всем возникающим вопросам обращайтесь к своему руководству.
Лицензия привязана к компьютеру и пользователю, для которых был сформирован идентификатор
инсталляции.

## Страница 21

В случае необходимости работы одного пользователя с разных компьютеров, либо разных
пользователей с одного компьютера, следует получать отдельную лицензию для каждой из
инсталляций.
Установка лицензии
Для установки полученный файл лицензии следует сохранить по
пути %UserProfile%\PlatformIDE\License.lic, где %UserProfile% - домашний каталог пользователя.
Если каталога PlatformIDE нет, то создайте его.
Название и расположение домашнего каталога зависит от типа операционной системы, например, в
Microsoft Windows он находится в каталоге Users и имеет название, соответствующее имени
пользователя системы. Например, C:\Users\Маша.
Для определения домашнего каталога в Windows следует выполнить в командной строке: echo
%UserProfile%.
После установки лицензии необходимо перезапустить ЦФТ-Среда разработки.
Состояние лицензии можно проверить в окне Oкно › Параметры… › ЦФТ-Среда разработки ›
License.

## Страница 22

Обновление версии ЦФТ-Среда разработки
Механизм обновления встроен в саму ЦФТ-Среда разработки.
 Дляcft-platform-ide-inst.exe.обновления ЦФТ-Среда разработки не нужно повторно запускать инсталлятор
После запуска ЦФТ-Среда разработки запускается автоматическое обновление в соответствии с
текущей конфигурацией. О запуске автообновления говорит появление значка в нижнем
правом углу окна.
Если ЦФТ-Среда разработки найдет обновление, пользователю автоматически будет предложено
его установить. Для подтверждения установки в окне [ Eclipse Update ] нужно нажать кнопку
[ Install ].
Проверить наличие обновлений можно и принудительно с помощью команды Cправка › Perfom
Setup Tasks…. И нажать кнопку [ Готово ] в окне [ Eclipse Updater ].
В случае, если обновлений нет, значок в правом нижнем углу окна будет выглядеть так .
После установки обновлений необходимо перезапустить ЦФТ-Среда разработки. 
Чтобы применить обновления, необходимо перезагрузить ЦФТ-Среда разработки. Для этого в
правом нижнем углу окна нажать значок .
В открывшемся окне [ Eclipse Updater ] нажать кнопку [ Готово ], после чего обновление
завершится.

## Страница 24

Обновление версии ЦФТ-Среда разработки,
в которой обновлены платформа Eclipse или
сторонние плагины
Обновление версии происходит в соответствии с пунктом Обновление версии ЦФТ-Среда
разработки.
В процессе обновления пользователю будет предложено подтвердить запрос на подпись
сертификата. В открывшемся окне [ Trust ] выделить предлагаемый сертификат и нажать кнопку
[ Trust Selected ]
После установки обновлений и последующей перезагрузки ЦФТ-Среда разработки откроется окно
[ Старая версия рабочей области ]. В нем необходимо подтвердить запрос на конвертацию
workspace, нажав кнопку [ Продолжить ], или выбрать новое рабочее пространство, нажав кнопку
[ Изменить рабочее пространство… ]. Далее запустится ЦФТ-Среда разработки.
