Услуга Установка и настройка ОС и средств ее мониторингаВ результате оказания услуги на аппаратно-программном комплексе (АПК) Банка будут установлены (и оптимальным образом сконфигурированы) операционная система, средства мониторинга (необходимые для контроля и передачи параметров работы АПК).
По завершению работ Банк получает отчет, содержащий все произведенные настройки и ключевые параметры АПК Банка, а также рекомендации для дальнейшей эксплуатации АПК.		1 097 901.00 руб.
Услуга Конфигурирование Системы Хранения ДанныхВ результате оказания услуги будет произведено конфигурирование системы хранения данных (СХД) для эксплуатации Платформы.
По завершению работ Банк получает отчет, содержащий все произведенные настройки и ключевые параметры СХД, а также рекомендации для дальнейшей эксплуатации СХД.		1 097 901.00 руб.
Услуга Установка СУБД и средств мониторинга СУБД на сервер БДВ результате оказания услуги на сервер Аппаратно-программного комплекса (далее АПК) Банка будут установлены СУБД и средства мониторинга ее работы, в том числе:
- выполнены все необходимые настройки СУБД
- СУБД  на АПК Клиента настроена оптимальным образом и подготовлена для установки прикладного ПО ЦФТ
- настроены компоненты мониторинга для контроля и передачи параметров работы СУБД (только для Oracle Database Enterprise Edition с опцией Diagnostics Pack).
По завершению работ Банк получает отчет, содержащий все произведенные настройки и ключевые параметры СУБД.		1 097 901.00 руб.
Услуга Установка и настройка сервера отчетовВ результате оказания услуги на сервер отчетов Аппаратно-программного комплекса (далее АПК) Банка будут установлены и настроены операционная система, ПО Oracle Fusion Middleware Forms and Reports, включая Weblogic Basic Server, и прикладное ПО ЦФТ. Сервер отчетов сконфигурирован для корректной работы в составе АПК.
По завершению работ Банк получает отчет, содержащий все произведенные настройки и ключевые параметры, определяющие работу сервера отчетов, а так же рекомендации для дальнейшей эксплуатации.		1 097 901.00 руб.
Услуга Установка и настройка сервера приложенийВ результате оказания услуги на сервер приложений Аппаратно-программного комплекса (далее АПК) Банка будут установлены и настроены операционная система, программное обеспечение сервера приложений и прикладное ПО ЦФТ. Сервер приложений сконфигурирован для корректной работы в составе АПК.
По завершению работ Банк получает отчет, содержащий все произведенные настройки и ключевые параметры, определяющие работу сервера приложений, а так же рекомендации для дальнейшей эксплуатации.		1 097 901.00 руб.
Услуга Установка и настройка балансировщика нагрузкиВ результате оказания услуги к Аппаратно-программному комплексу (далее АПК) Банка будет подключен, сконфигурирован и настроен Балансировщик нагрузок для работы с серверами приложений АПК.
По завершению работ Банк получает отчет, содержащий все произведенные настройки и ключевые параметры, определяющие работу балансировщика, а так же рекомендации для дальнейшей эксплуатации.		1 097 901.00 руб.
Услуга Настройка кластера в режиме RAC, добавление узла кластера RAC (только для СУБД Oracle)В результате оказания услуги на серверах Аппаратно-программного комплекса (далее АПК) Банка будет организован кластер по технологии Oracle Real Application Clusters (возможно не для всех типов прикладного ПО). Добавлено согласованное число узлов в кластер.
По завершению работ Банк получает отчет, содержащий все произведенные настройки и ключевые параметры кластера, а та же рекомендации для дальнейшей эксплуатации СУБД Oracle.		1 097 901.00 руб.
Услуга Установка дистрибутива пакета прикладного ПОВ результате оказания услуги на Аппаратно-программный комплекс (далее АПК) Банка будет установлен и сконфигурирован дистрибутив прикладного программного обеспечения (далее ПО) ЦФТ с учетом конфигураций сервера, СУБД  и системы хранения данных.
По завершению работ Банк получает отчет, содержащий все произведенные настройки и ключевые параметры прикладного ПО.		1 097 901.00 руб.
