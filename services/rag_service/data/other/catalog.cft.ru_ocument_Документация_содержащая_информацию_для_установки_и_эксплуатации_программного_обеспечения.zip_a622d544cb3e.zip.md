## Страница 3

Установка ЦФТ-Среда разработки
Установка и обновление ЦФТ-Среда разработки выполняется с использованием сайтов обновлений,
представляющих собой хранилища модулей, используемых приложением.
Доступны три варианта установки и обновления ЦФТ-Среда разработки:
• Online установка/обновление. Сайт обновлений находится на сервере ЦФТ. Необходимо
наличие доступа в Интернет с рабочего места пользователя в процессе первоначальной
установки и последующего обновления ранее установленного продукта. См. Online установка.
• Offline установка/обновление из зеркала в Nexus Repository Manager 3 OSS. Сайт
обновлений располагается на Nexus сервере во внутренней сети организации. Доступ в
Интернет с рабочего места пользователя не требуется. См. Offline установка из зеркала в Nexus
Repository Manager 3 OSS.
• Offline установка/обновление из файлового зеркала в локальной сети. Сайт обновлений
располагается во внутренней сети организации. Доступ в Интернет с рабочего места
пользователя не требуется. См. Offline установка из файлового зеркала.
• Offline установка/обновление из http-сервера. Сайт обновлений располагается на http-
сервере во внутренней сети организации. Доступ в Интернет с рабочего места пользователя не
требуется. См. Offline установка из http-сервера.

## Страница 5

Offline установка из зеркала в Nexus
Repository Manager 3 OSS
В данном режиме установка и обновление будет происходить с сайта обновлений, расположенного
на сервере Nexus Repository Manager 3 OSS (далее Nexus) во внутренней сети организации. Доступ
в Интернет с рабочего места пользователя не требуется.
Nexus позволяет создать локальную копию сайтов обновлений ЦФТ. При выпуске новой версии ЦФТ-
Среда разработки, она будет автоматически скачена при первой попытке обновления. Последующие
обновления до новой версии будут происходить с локальной копии, сохраненной на Nexus сервере.
Данная версия является свободно распространяемым ПО. Скачать его можно по ссылке:
https://www.sonatype.com/nexus-repository-oss.
Официальная документация доступна по ссылке: https://help.sonatype.com/repomanager3.
Как работает Nexus:
• При обращении к Nexus с любого рабочего места, на котором запущено обновление ЦФТ-Среда
разработки, происходит проверка наличия нужной версии плагина в зеркале репозитория.
• Если нужная версия найдена в зеркале, то она возвращается в ответе на запрос.
• Если нужная версия не найдена в зеркале, то Nexus обратится за ней на сайт сопровождения.
• Если на сайте сопровождения нужная версия найдена, то она сохраняется в зеркало и
возвращается в ответе на запрос.
• Если на сайте сопровождения нужная версия не найдена, то возникнет ошибка обновления.

## Страница 12

Offline установка из файлового зеркала
В данном режиме установка и обновление будет происходить с сайта обновлений ЦФТ-Среда
разработки, расположенного локальной сети организации. Доступ в Интернет с рабочего места
пользователя не требуется.
Необходимо предоставить доступ к сетевой папке offline-зеркала со всех рабочих мест
пользователей.
Первичная настройка и последующее периодическое обновление offline-зеркала выполняется
вручную сотрудником организации.
Для обновления offline-зеркала достаточно повторить шаги, описанные в разделе Создание
файлового зеркала. Повторной настройки инсталлятора и/или конфигурации не требуется.
Создание файлового зеркала
Для создания файлового offline-зеркала с последней версией ЦФТ-Среда разработки необходимо

# ЦФТ-Среда разработки

Описание основных функциональных характеристик. Инструкция для разработчиков («первые шаги»).

АО «ЦФТ»

01/04/2025

### Введение

Система «ЦФТ-Среда разработки» (далее – «Система», «Среда разработки») предназначена для индивидуальной и коллективной разработки бизнес-приложений на трех архитектурных уровнях:

Структура хранения данных бизнес-приложения;

Поведение бизнес-приложения;

Пользовательский интерфейс бизнес-приложения.

При этом Система бесшовно интегрирует все эти уровни между собой и обеспечивает органичную интеграцию кода бизнес-приложений АО «ЦФТ» (далее – «ЦФТ») и кода локального бизнес-приложения, разработанного потребителями бизнес-приложений ЦФТ (далее – «клиенты»).

Ключевой возможностью является работа с исходными кодами бизнес-приложений в виде файлов на языке PL+. Файлы объединяются в индивидуальные компоненты (проекты), образующие бизнес-приложение. Среда разработки интегрируется с современными системами контроля версий, благодаря чему разработчики могут оперативно установить авторство изменений, группировать изменения по задачам, проектам, оперативно извлекать и развертывать предыдущие версии объектов и т.д.

Инструмент включает прекомпилятор исходного кода с языка PL+ на исходный язык java, а также содержит отладчик кода.

Свобода в выборе системы и стратегии управления исходным кодом позволяет выстраивать коллективный процесс с максимальным учетом особенностей продукта и команды разработки.

Среда разработки поддерживает практики CI (Continuous Integration — непрерывная интеграция) и DevOps (development & operations — активное взаимодействие и интеграция разработчиков и специалистов по ИТ обслуживанию, помогающие быстрее создавать и обновлять программные продукты и сервисы).

Среда разработки обновляется автоматически из настроенного репозитория её компонент.

Разработчики имеют возможность программирования в автономном режиме, за исключением выполнения операций, требующих сетевого подключения к базе данных.

Разработчик бизнес-приложений может сформировать внешний вид среды разработки под свои потребности – разместить окна на нескольких мониторах, выбрать цветовую гамму, то есть максимально персонализировать свое рабочее место, что значительно повышает комфорт разработки.

Инструментарий обеспечивает возможность проверки совместимости локальных решений клиента с новыми версиями бизнес-приложений ЦФТ на уровне API без участия ЦФТ и без необходимости развертывания бизнес-приложений в базе данных.

### Основные функции

Среда разработки является основным рабочим модулем разработчика и позволяет:

проектировать структуру/модель прикладных объектов (типов данных) достаточной сложности;

разворачивать спроектированные структуры/модель в системе хранения данных СУБД;

проектировать в дизайнере витрины/представления данных;

проектировать в дизайнере экранные формы методов, выполняемых на клиентском месте пользователя;

описывать алгоритмы обработки прикладных объектов на высокоуровневом языке PL+, поддерживающим объектную модель данных;

компилировать исходные коды на языке PL+ в исходный код для java среды исполнения;

автоматически добавлять в генерируемый код проверку назначенных пользователю прав;

назначать бизнес-пользователям предельно детализированные права на просмотр и обработку прикладных объектов.

Система обеспечивает следующую функциональность:

### Полноценная интеграция с современными системами контроля версий

Ведение нескольких веток разработки

Переключение между ветками

Восстановление состояния приложения из истории

### Современные редакторы исходного кода

Синтаксическая проверка «на лету» в процессе кодирования

Контекстные подсказки

Навигация по коду

Интерактивный доступ к списку функций и процедур, навигация по функциям и переход от структуры к коду и обратно

### Средства коллективной разработки в одной БД

Возможность просмотра списка различающихся объектов и их отличий непосредственно при развертывании изменений бизнес-приложения

Блокировки объектов модели при модификации

Визуальные оповещения

### Полный контроль при внесении существенных изменений в код

Моделирование изменений любых изменений без необходимости развертывания изменений в БД

Интерактивный рефакторинг кода

### Статический анализ кода бизнес-приложения

Ссылочная целостность

Зависимости

Иерархия вызовов

### Кастомизация рабочего места разработчика

Цветовые схемы

Поддержка многомониторных конфигураций

Кастомизация размещения окон

### Создание унифицированных бизнес-приложений, независимых от баз данных

При соблюдении определённых правил разработки (ANSI SQL, отсутствие СУБД-специфичных возможностей) возможно создание унифицированных бизнес-приложений, поддерживающих различные СУБД (например, и СУБД Oracle, и СУБД PostgreSQL)

Обеспечивает бизнес-приложения средствами взаимодействия c БД линейки PostgreSQL.
