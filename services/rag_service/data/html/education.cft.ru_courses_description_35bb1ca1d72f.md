# Налоговый учёт

дистанционно

4

Комплекс приложений «Налоговый учет» предназначен для упрощения и автоматизации сбора информации, необходимой для получения налоговых деклараций. Комплекс приложений предназначен для реализации требований 25-ой, 28-ой, 30-ой, 31-ой главыНалогового кодекса РФ.

Комплекс приложений в части поддержки требований 25-ой главы НК РФ решает следующие задачи:

- ​Обработка данных по различным направлениям деятельности банка в целях налогового учета
- Настройка и формирование регистров налогового учета
- Расчет налогооблагаемой базы
- Сверка данных налогового учета с данными бухгалтерского учета
- Расчет налоговой декларации по налогу на прибыль организаций
- Экспорт данных налоговой декларации на прибыль организаций в формат XML

​Комплекс приложений в части поддержки требований 28-ой, 30-ой, 31-ой глав НК РФ решает следующие задачи:

- ​Расчет налоговых деклараций по транспортному налогу, налогу на имущество и земельному налогу
- Экспорт данных налоговых деклараций в формат XML
- Сохранение в системе расшифровок данных, попавших в налоговые декларации
- Формирование налоговых регистров на основе сохраненных расшифровок

Курс состоит из одинадцати разделов:

1. ​​Общая схема работы с продуктом
2. Формирование списка сделок с взаимозависимыми лицами и контролируемых сделок​
3. Формирование аналитических данных для учета процентных доходов и расходов по долговым обязательствам​
4. Формирование аналитических данных для расчета налога на основе данных по депозитам​
5. Формирование аналитических данных для расчета налога на основе данных по кредитам, гарантиям и МБК
6. Формирование аналитических данных для расчета налога на основе данных по ВХО
7. Формирование аналитических данных для расчета налога на основе данных РКО, конверсионных операций, а также на основе данных лицевых счетов
8. Формирование налоговых регистров
9. Формирование НОБ и декларации
10. Учет отложенных налоговых обязательств и отложенных налоговых активов
11. Формирование деклараций по транспортному налогу, налогу на имущество организаций и земельному налогу
