# Операции на срочном рынке. Операции клиентов по договорам брокерского обслуживания на Московской бирже (FORTS)

Форма: дистанционно

Продолжительность (значение сайта; единица не указана в HTML): 9

Функциональность приложений учета биржевых сделок с производными финансовыми инструментами (ПФИ) рынка FORTS Московской биржи предназначена для ведения сделок и операций клиентов, совершаемых по договорам брокерского обслуживания.

Комплекс приложений позволяет:

- регистрировать сделки клиентов с ПФИ, совершенные по договорам брокерского обслуживания
- учитывать операции клиентов по договорам брокерского обслуживания
- вести бухгалтерский учет операций клиентов по договорам брокерского обслуживания в соответствии с правилами нормативных документов Банка России
- вести внутренний учет операций клиентов по договорам брокерского обслуживания в соответствии с правилами ведения внутреннего учета профессионального участника рынка ценных бумаг, осуществляющими брокерскую деятельность

Вы узнаете:

- Как зарегистрировать сделку клиента с фьючерсами или опционами на фьючерс
- Какие действия необходимо выполнить для обработки сделки и формирования документов бухгалтерского учета и внутреннего учета
- Как рассчитать комиссионное вознаграждение по сделкам, совершенным по брокерскому договору
- Как получить отчетность в части группировки данных по сделкам с ценными бумагами в соответствии с правилами ведения внутреннего учета профессионального участника рынка ценных бумаг, осуществляющими брокерскую деятельность

Вы поймёте:

- Принципы и порядок учёта операций с биржевыми производными финансовыми инструментами, совершенными по договорам брокерского обслуживания, в системе «ЦФТ-Банк»

Вы научитесь:

- Регистрировать брокерскую сделку, заключенную на рынке FORTS Московской бирже
- Выполнять операции по договору брокерского обслуживания
- Выполнять операции для бухгалтерского и внутреннего учёта ПФИ клиентов по договорам брокерского обслуживания в правильной последовательности
