# Учетное ядро. Счета и планы счетов

дистанционно

4

​Для отражения совокупности имущества и учёта различных операций в системе организовано хранение информации по счетам в виде иерархической структуры плана счетов. Внутри неё лицевые счета группируются для получения отчётной информации в соответствии с этой группировкой. Количество планов счетов и способы группировки в общем случае произвольны и определяются средствами администрирования.

**Цели курса**

Вы узнаете:

- Каким образом в системе организовано хранение информации по счетам
- Какова структура плана счетов, и какие возможности и ограничения существуют для создания собственной иерархии по счетам
- Правила формирования, дополнения, удаления глав, разделов, счетов 1-го и 2-го порядков
- Какие представления для просмотра данных реализованы в системе
- Каковы особенности обработки балансовых счетов 2 порядка при проводке платежных документов
- Какие сервисные и служебные операции предложены в системе
- Каким образом выполняется проверка баланса на начало дня
- Механизм формирования архива учетных счетов и его пополнения

Относительно финансовых (лицевых) счетов вы узнаете:

- Специфику работы с парными счетами
- Как посмотреть плановый остаток по счету
- Некоторые правила открытия лицевых счетов (порядок формирования номера лицевого счета, правила формирования наименования счета)

Вы научитесь:

- Создавать собственную иерархию счетов
- Открывать и закрывать финансовый счет, удалять ошибочно открытые счета
- Открывать счет с подтверждением
- Назначать ответственного по счету, изменять характеристики счета
- Формировать сообщения в налоговые органы и социальные фонды об открытии/закрытии или изменении реквизитов счетов
