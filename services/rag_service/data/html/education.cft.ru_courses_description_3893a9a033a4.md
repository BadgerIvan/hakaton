# ЦФТ-СЭД. Обмен с контрагентами

Дистанционно

2

​

ЦФТ-СЭД — эффективный инструмент для обмена юридически значимыми электронными документами с контрагентами и организации подписания и хранения внутренних электронных документов в соответствии с требованиями Федерального закона № 63-ФЗ «Об электронной подписи».

ЦФТ-СЭД позволяет обмениваться с контрагентами следующими типами документов:

- Счета на оплату
- Счета-фактуры
- Товарные накладные ТОРГ-12
- Акты приемки-сдачи выполненных работ
- УПД
- Неформализованные документы

Система ЦФТ-Система автоматизированного обмена является интеграционным решением, которое обеспечивает взаимодействие Учетной системы (в текущей версии системы ЦФТ-Банк) и системы оператора электронного документооборота (далее ЭДО).

**Курс содержит:**

- Информационные материалы (файлы на вкладке «Дополнительные материалы» в карточке курса)
- Тест для самопроверки
- Контрольный тест

**Целевая аудитория**
Все специалисты, работающие в системе «ЦФТ-Банк» (Платформа 1)

**Цели курса:**

Вы узнаете:

- Какие настройки необходимо произвести перед началом документооборота
- Как создавать документы различных типов для передачи их контрагентам
- Какие роли можно задать пользователю в ЦФТ-СЭД
- Какие статусы принимают документы в электронном документообороте

Вы научитесь:

- Настраивать маршрут для согласования
- Настраивать ролевую структуру и права пользователей ЦФТ-СЭД
- Заводить контрагентов-участников ЭДО
- Формировать документы для отправки контрагентам
- Получать входящие документы в ЦФТ-Банк
