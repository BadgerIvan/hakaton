# Тестовые дни

В рамках оказания услуги совместная Проектная группа Клиента и ЦФТ проводит тренинг по использованию Приложений для сотрудников Клиента на тестовой схеме Клиента (тестовый день).

 Целью тренинга (тестового дня) является проверка:

- Взаимодействия подразделений Клиента при использовании Приложения,
- Работоспособности Приложения в комплексе взаимосвязанных Приложений,
- Взаимодействия Приложения с внешними системами Клиента.

В рамках данной услуги предоставляются консультации по следующим направлениям:

- Консультации участников Проектной команды Клиента в части подготовки программы, методики, контрольных примеров для проведения тренинга,
- Разработка почасового плана перевода Приложения в эксплуатацию и отработка по нему действий Проектных команд Клиента, ЦФТ, сторонних организаций (в случае необходимости, например, по внешним системам),
- Предоставление рекомендаций по устранению замечаний в части ответственности Клиента,
- Организация оперативного мониторинга и распределения запросов, поступающих от пользователей Приложений между соответствующими специалистами Проектных команд Клиента и ЦФТ.
