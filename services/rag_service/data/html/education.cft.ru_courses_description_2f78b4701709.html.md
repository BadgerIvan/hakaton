# Бэк-офис пластиковых карт. Сопряжение с внешними системами

Форма: дистанционно

Продолжительность (значение сайта; единица не указана в HTML): 4

Взаимодействие с внешними процессинговыми системами осуществляется посредством файлового обмена следующим образом:

- в системе формируются файлы с запросами по управлению клиентами, картами и карт-счетами, изменению лимита авторизации;
- из процессингового центра приходит файл-ответ.

Результатом обработки файла-ответа может быть изменение статуса карты, присвоение номера карте, изменение срока действия и т.д. Посредством файлового обмена также осуществляются изменение и сверка остатков по картам, обработка транзакции по картам и терминалам.

**Цель курса**

Вы узнаете:

- каковы основные этапы настройки системы для возможности работы с процессингами «OWS», «Compass Plus», «Smart Vista», «UCS», «КартСтандарт», платежной системой «Мир»
- какие существуют варианты формирования, загрузки и обработки файлов запросов на управление картами\карт-счетами и запросами на изменение лимита авторизации в системе для процессингов «OWS», «Compass Plus», «Smart Vista», «UCS», «КартСтандарт», платежной системой «Мир».

Вы поймете, как осуществляется взаимодействие с процессингами «OWS», «Compass Plus», «Smart Vista», «UCS», «КартСтандарт», платежной системой «Мир»

Вы научитесь:

- настраивать карточные справочники для возможности работы с процессингом,
- выполнять операции, обеспечивающие взаимодействие процессинга с системой.
