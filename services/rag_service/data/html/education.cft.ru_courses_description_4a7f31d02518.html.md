# Договоры страхования в системе «ЦФТ-Банк Розница 2MCA»

Форма: дистанционно

Продолжительность (значение сайта; единица не указана в HTML): 6

Продукт «Розница. Договоры страхования» входит в подсистему «ЦФТ-Банк Розница 2MCA», реализованную на основе логики «ЦФТ-Банк» и технологической платформы 2 МСА. В продукте «Розница. Договоры страхования» выполняется учёт и ведение договоров страхования и нестраховых агентских продуктов. «Розница. Договоры страхования» позволяет автоматизировать все основные виды операций по договорам страхования и по договорам нестраховых агентских продуктов.

Курс предназначен для дистанционного обучения команды внедрения банка основным правилам работы с продуктом «Розница. Договоры страхования».

**Вы узнаете:**

- Основные понятия продукта «Розница. Договоры страхования»
- Какие схемы страхования поддерживает продукт
- Технологию настройки справочников, которые используются для работы с продуктом «Розница. Договоры страхования»
- Как выполняется настройка видов страхования и программ страхования
- Какие настройки необходимы для выполнения операций по договорам страхования
- Об основных операциях по договорам страхования
- Какие настройки необходимо выполнить для учёта страховых случаев
- О добавлении новых видов страховых случаев, регистрации и обработке страховых случаев
- Какие настройки необходимо выполнить для формирования страховых реестров
- Как формировать, редактировать и оплачивать страховые реестры
