# Резервирование в системе «ЦФТ-Банк Розница 2MCA»

Форма: дистанционно

Продолжительность (значение сайта; единица не указана в HTML): 6

«Розничное резервирование» – часть подсистемы «Розница». Продукт взаимосвязан с продуктом «Розница. Кредиты». Основная особенность розничной подсистемы – использование фактических операций для анализа изменений данных в резервировании, что обеспечивает формирование резервов без обращения к остаткам по аналитическим счетам. Курс рассчитан на слушателей курса «Розница. Кредиты».

**Вы узнаете:**

1. Основные понятия розничного резервирования
2. О взаимосвязи кредитного договора и продукта резервирования
3. Основные реквизиты продукта резервирования
4. О настройках видов операций для резервирования
5. О портфельном резервировании
6. Структуру настроек видов портфелей
7. Об индивидуальном резервировании
8. Основные операции резервирования
