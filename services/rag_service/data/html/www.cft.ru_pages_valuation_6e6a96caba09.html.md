# Оценка качества исходных данных

Клиент предоставляет экспортные данные, соответствующие  существующим форматам импорта данных в Приложения. В рамках оказания услуги  ЦФТ предоставляет консультации относительно качества и полноты экспортных данных.

В рамках данной услуги предоставляются консультации по следующим направлениям:

- Консультации в части заполнения структур исходных данных для их последующего импорта в Приложения,
- Предоставление проектной группе клиента рекомендаций в части повышения качества данных в унаследованных системах,
- Консультации по выверке данных с помощью специализированных автоматизированных процедур,
- Проведение автономных испытаний конвертации данных.
