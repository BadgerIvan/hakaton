# О компании

ЦФТ (Центр Финансовых Технологий) – ведущий российский разработчик и поставщик технологических решений для финансовой индустрии. Компания специализируется на проектировании, разработке и тиражировании решений для всех направлений деятельности кредитно-финансовых организаций.

Флагмантский продукт в линейке разработок компании –
[система ЦФТ-Банк](https://catalog.cft.ru/applications/cftbank/overview). Решение является отраслевым стандартом промышленных отечественных core banking систем по функциональности, интеграционным возможностям, масштабируемости, стабильности работы.  Информационный комплекс ЦФТ-Банк является лидером по числу инсталляций в российских банках TOП-50.  Решение входит в
[Реестр российского ПО](https://reestr.digital.gov.ru/reestr/303817/?sphrase_id=2118121).
