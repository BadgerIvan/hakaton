# Кредиты. Учёт и распределение обеспечения

Форма: дистанционно

Продолжительность (значение сайта; единица не указана в HTML): 4

Приложения комплекса «Учёт и распределение обеспечения» позволяют полностью организовать процесс регистрации, учёта и распределения договоров обеспечения для минимизации резервов в соответствии с Положением № 590-П «О порядке формирования кредитными организациями резервов на возможные потери по ссудам, по ссудной и приравненной к ней задолженности» и 283-П «О порядке формирования кредитными организациями резервов на возможные потери».

Система позволяет автоматизировать учёт полученного по кредитному договору обеспечения и залоговых ценностей.

**Цели курса**

Вы узнаете:

•Каковы основные правила ведения учёта обеспечения

•Каковы правила расчёта долей обеспечения для формирования резерва

Вы поймете:

•Каким образом осуществляется учёт обеспечения

•Какие существуют способы распределения обеспечения на кредитные договоры

•Алгоритм расчёта качества обеспечения кредита

Вы научитесь:

•Вести учёт обеспечения:

– Регистрацию договоров обеспечения

– Регистрацию залоговых ценностей

– «Настройку логики продукта» для продукта «Договоры обеспечения»

– Открывать внебалансовые счета для учёта обеспечения

– Формировать внебалансовые документы по учёту и списанию сумм обеспечения

– Привязывать один договор обеспечения к нескольким кредитным договорам

– Закрывать договор обеспечения
