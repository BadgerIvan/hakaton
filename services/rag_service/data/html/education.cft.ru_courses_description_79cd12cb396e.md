# Учетное ядро. Безналичный документооборот

дистанционно

4

Для создания безналичных документов в системе реализован «Универсальный конструктор безналичного документа», позволяющий сформировать различные виды платёжных документов. Каждый тип безналичных документов имеет свои особенности при создании. Имеются шаблоны документов, в которые можно сохранить заполненные реквизиты плательщика и получателя, а также назначение платежа. Реквизиты любой сторонней организации, не являющейся клиентом кредитной организации,
 могут быть занесены в справочник «Контрагенты» для ускорения ввода документов. В системе реализована возможность двойного ввода платежных документов в национальной валюте и поиска документов для подтверждения реквизитов. Также реализована возможность сканирования и распознавания платежных документов на бумажном носителе, которая позволяет существенно снизить время, необходимое на ввод в систему документов с бумажного носителя.

**Цели курса**

Вы узнаете правила создания безналичного документа, а именно:

- Особенности заполнения полей при создании безналичного документа (основные и дополнительные реквизиты).
- Специфику создания мультивалютных документов.
- Специфику создания платежных требований.
- Специфику создания бюджетных документов.
- Дополнительные возможности, предусмотренные в системе для ускорения работы с безналичными документами: сохранение шаблонов ввода документов, справочник «Контрагенты», маршрутизация.
- Как организовать двойной ввод документов.
- Как найти документы для подтверждения контролером.
- О возможности автоматизации процесса импорта платежных документов из системы сканирования и распознавания документов (СРД) Finereader-Bank для формирования их в виде электронного документа системы.

Вы поймете:

- Какой путь проходит безналичный документ в системе.

Вы научитесь:

- Создавать безналичные документы разных типов, используя при этом дополнительные возможности системы по ускорению и облегчению этого процесса.
