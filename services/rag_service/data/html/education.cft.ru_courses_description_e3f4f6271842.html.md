# Бэк-офис пластиковых карт. Ведение лимитов авторизации. Работа с балансами

Форма: дистанционно

Продолжительность (значение сайта; единица не указана в HTML): 4

​Система позволяет контролировать и, в случае расхождения лимитов, предоставляет
ряд расчетных величин для диагностики причин расхождения, упрощая работу
пользователя по разбору конфликтных ситуаций. Также существует удобный интерфейс
для получения информации о текущем балансе клиента по карте и карт-счету,
выписке и последних операций по счету, а также для управления остатками по
карт-счетам клиентов.
