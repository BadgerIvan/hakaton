# Единый расчетный центр

## Краткое описание

Готовое IT-решение для информационно-технологической поддержки единого казначейства Группы компаний

## Описание

Единый расчетный центр корпорации (ЕРЦК) – готовое IT-решение для информационно-технологической поддержки единого казначейства Группы компаний.

Решение обеспечивает специалистов единого казначейства полной информацией о счетах, открытых дочерними организациями или подконтрольными обществами, и финансовых потоках по ним.

Функциональные возможности ЕРЦК позволяют автоматизировать единый расчетный центр группы организаций и решить следующие задачи:

- Создание единого, управляемого и контролируемого бизнес-процесса осуществления платежей – от согласования заявки на платеж до отправки документа в банк
- Автоматическая отправка платежей в банки и получение оперативной информации о результате обработки платежных документов в банке
- Оперативный анализ остатков и движения средств по счетам всех организаций группы по факту получения выписок из банков
- Формирование пакета необходимых документов по контрактам с нерезидентами для отправки в банк в требуемом законодательством формате

Решение настраивается под IT-архитектуру организаций группы, возможно развитие его функционала в соответствии с требованиями бизнеса.

Все цены приведены без учета НДС. НДС рассчитывается согласно действующему законодательству РФ. Цены не включают стоимости лицензии на использование ПО третьих лиц (например, СУБД).
