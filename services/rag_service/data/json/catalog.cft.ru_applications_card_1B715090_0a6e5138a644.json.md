## Описание

## Управление лимитами при выполнении факторинговых операций.

Приложение позволяет использовать централизованную систему управления лимитами с целью автоматизации акцепта, переоценки и мониторинга лимитов по факториновым операциям. С помощью Приложения, Вы сможете повысить качество управления портфелем факторинговых сделок, а также использовать лимиты как способ определения кредитных полномочий сотрудников банка.

## Функциональные возможности

- Установка значений следующих критериев лимитов по факториновым операциям:

- Подразделение
- Пользователь
- Вид договора факторингового обслуживания/соглашения
- Валюта договора факторингового обслуживания/соглашения
- Срок договора факторингового обслуживания/соглашения
- Клиент/Группа клиентов
- Подразделение должника/должник/группа должников

- Настройка характеристик контроля лимитов в разрезе следующих операций:

- Учет информации о дебиторской задолженности на основании документов/контрактов между клиентом и должником
- Учет получаемых прав требования по соглашениям (с финансированием/без финансирования)
- Исполнение обязательств клиента
- Исполнение обязательств подразделения должника должника
- Изменение условий договора факторингового обслуживания/соглашения

- Контроль соблюдения установленных значений лимитов при

- Регистрации/редактировании/подписании договора факторингового обслуживания/ соглашения
- Регистрации/ подписании/удалении дополнительных соглашений по договорам факторингового обслуживания/ соглашениям
- Исполнении/удалении финансовых распоряжений
- Создании/удалении фактических операций
