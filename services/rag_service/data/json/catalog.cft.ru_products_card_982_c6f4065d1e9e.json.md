# Пополнение счетов клиента (погашение кредитов) наличными

**Каталог:** ЦФТ-Банк

**Код продукта:** 012214010001

**Направление продукта:** Частным лицам

**Группа:** Дистанционные сервисы

**Подгруппа:** Устройства самообслуживания

## Краткое описание

Зачисление наличных денежных средств на счета клиентов без использования банковских карт в on-line режиме через устройства самообслуживания и устройства, установленные в торгово-сервисных точках.

**Необходимые приложения (коды):**  1B690080, 1B690100, 1B690110, 1B690055, 1B690125, 1B690120

**Рекомендуемые приложения (коды):**  1B690060, 1B690090

## Примеры настройки продукта из каталога

Это параметры примера настройки, а не условия конкретного банка.

## Настройка 1

Идентификатор для авторизации клиента

## Пример 1

В справочнике "Карты. Сервер доступа. Набор параметров для идентификации клиента и счета клиента" настраиваются наборы параметров для идентификации: по номеру карты, номеру договора, номеру счета, ХЭШу номера карты, а также по комбинациям из этих основных параметров и дополнительных: ФИО, номера документа, номера телефона. Настроенные наборы должны соответствовать параметрам в устройстве самообслуживания, либо торгово-сервисной точке.

## Настройка 2

Текст для отображения на экране и чеке устройства самообслуживания

## Пример 2

В справочнике "Настройки." настраивается "Сервер доступа. Текст для отображения на экране/чеке" в разрезе типов договоров, по которым предоставляется информация "Депозит" или "Кредит", а также типов запросов от устройства. При настройке используются вычисляемые параметры, которые возвращают номер договора, счета, дату обязательного платежа, задолженность клиента и другую справочную информацию.

## Настройка 3

Отображение информации по видам кредитов

## Пример 3

В справочнике "Виды кредитов" путем установки признака "Доступен для просмотра" настраивается возможность просмотра клиентами в устройствах самообслуживания информации по данному виду кредита.
