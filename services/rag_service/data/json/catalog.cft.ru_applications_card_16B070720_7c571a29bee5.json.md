## Формирование Примечания 63 к Положению 526-П.

Приложение позволяет получить отчет о передаче финансовых активов. Автоматическая обработка данных сократит временные затраты сотрудников страховой организации на формирование отчета и снизит вероятность возникновения ошибок.

## Функциональные возможности

- Расчет показателей отчета о передаче финансовых активов
- Расчет показателей отчета по остаткам, оборотам по финансовым счетам
- Получение отчета по филиалу / сводного отчет
- Вывод данных отчета в тысячах рублей
- Формирование протоколов расчета отчета в формате CSV, MS Excel
- Формирование файлов расчета отчета в формате MS Excel, XML
