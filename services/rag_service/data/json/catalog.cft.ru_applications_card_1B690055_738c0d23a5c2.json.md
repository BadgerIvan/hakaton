## Краткое описание

Предоставьте клиентам возможность интерактивного взаимодействия с банком через устройство самообслуживания с целью получения информации по своим счетам

## Описание

## Предоставьте клиентам возможность интерактивного взаимодействия с банком через устройство самообслуживания с целью получения информации по своим счетам.

Приложение позволяет клиенту банка после авторизации в устройстве самообслуживания получать информацию о списке счетов, открытых на его имя, и списке операций, доступных по выбранному счету. Приложение обеспечивает расчёт и удержание комиссии по каждой операции, выполняет передачу информации по комиссии для отображения клиенту в устройстве. Определение индивидуальной настройки доступа к счетам и информации по счету клиента в устройстве повысит качество обслуживания клиентов через устройство самообслуживания.

## Функциональные возможности

- Автоматическое извлечение сообщений от процессингового центра с помощью универсального шлюза "Интегратор" с запросами:

- списка счетов
- информации по счету и списка операций

- Разбор и проверка входящих сообщений в соответствии с поставляемым форматом
- Ведение журнала входящих сообщений по операциям в устройстве самообслуживания с отражением информации по итогам обработки каждого сообщения
- Идентификация клиента в системе ЦФТ-Банк по номеру и сроку действия карты
- Настройка доступа в устройстве самообслуживания в разрезе различных параметров:

- к счетам клиента
- к операциям по счету
- к информации по счетам

- Получение списка счетов, доступных клиенту в устройстве
- Получение информации и списка доступных операций по каждому счету клиента в устройстве
- Настройка шаблона для отображения информации по счету
- Расчет и удержание комиссий за выполнение операций (при наличии настройки)
- Формирование ответного сообщения в процессинговый центр согласно поставляемому формату ответа на полученные сообщения
- Автоматическая выгрузка ответных сообщений с помощью универсального шлюза "Интегратор"
