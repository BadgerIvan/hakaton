# Главная книга для МФО

## Краткое описание

Готовое решение ЦФТ представляет собой комплекс приложений для полной автоматизации бизнес-процессов микрофинансовой организации

## Описание

Готовое решение ЦФТ представляет собой комплекс приложений для полной автоматизации бизнес-процессов микрофинансовой организации (ломбарды, кредитные потребительские кооперативы, лизинговые компании). Функционал включает оформление заявки, полную проверку информации по клиенту (СМЭВ, БКИ, противодействие легализации, OFAC, черные списки), оформление и обслуживание кредитных договоров, организацию взаимодействия с заемщиком, мониторинг просроченных кредитов, учет договоров покупки/продажи кредитных портфелей.

Все цены приведены без учета НДС. НДС рассчитывается согласно действующему законодательству РФ. Цены не включают стоимости лицензии на использование ПО третьих лиц (например, СУБД).
