# ЦФТ-Среда разработки

## Краткое описание

Ведение индивидуальной и/или коллективной разработки по созданию бизнес-приложений с помощью языка PL+

## Описание

Программный комплекс «ЦФТ-Среда разработки» (далее – «Система») предназначен для ведения индивидуальной и/или коллективной разработки по созданию бизнес-приложений с помощью языка PL+. Система разработана на базе свободно распространяемой платформы Eclipse.

Основные функции:

1. Полноценная интеграция с современными системами контроля версий
2. Современные редакторы исходного кода
3. Средства коллективной разработки
4. Полный контроль при внесении существенных изменений в код
5. Статический анализ кода бизнес-приложения
6. Кастомизация рабочего места разработчика
7. Создание унифицированных бизнес-приложений, независимых от баз данных
8. Поддержка преемственности бизнес-приложений ЦФТ, разработанных для различных программных комплексов АО «ЦФТ», и последующего перехода для их эксплуатации с СУБД PostgreSQL

Данное описание решения приведено для предварительного ознакомления с функциональностью Системы и может не содержать исчерпывающий список условий и ограничений. Точные характеристики Системы отражены в сопроводительной документации.

Все цены приведены без учета НДС. НДС рассчитывается согласно действующему законодательству РФ. Цены не включают стоимости лицензии на использование ПО третьих лиц (например, СУБД).
