## Краткое описание

Внутренний учет внебиржевых сделок с эмиссионными ценными бумагами по договорам Общего Фонда Банковского Управления

## Описание

## Внутренний учет внебиржевых сделок с эмиссионными ценными бумагами по договорам Общего фонда банковского управления.

Приложение предоставляет весь необходимый набор процедур по внутреннему учету операций с эмиссионными ценными бумагами ОФБУ на внебиржевом рынке: от регистрации договора и ввода денежных средств или ценных бумаг до расчетов по сделкам и удержания вознаграждения управляющего. Формирование требуемых журналов и регистров выполняется автоматически. Приложение обеспечивает внутренний учет, основываясь на данных, регистрируемых в Приложении по бухгалтерскому учету сделок, без необходимости повторного ввода данных.

Приложение позволит уменьшить вероятность ошибок и ускорить получение регистров и отчетов.

## Функциональные возможности

- Поддерживаются следующие объекты учета:
  - Ведение договоров доверительного управления имуществом с объединением имущества учредителя в единый имущественный комплекс (Общий фонд банковского управления) наряду с имуществом других лиц по следующим объектам доверительного управления: эмиссионные ценные бумаги и денежные средства для инвестирования в ЦБ
  - Поручения на сделки и на операции с эмиссионными ценными бумагами и денежными средствами
  - Внебиржевые сделки с эмиссионными ценными бумагами ОФБУ
  - Счета ВУ по учету ДС
  - Счета ВУ по учету ЦБ
  - Иные операции с ЦБ (выплата дивидендов, погашение купона, частичное и полное гашение облигации)
  - Ведение портфеля лотов ценных бумаг ОФБУ по учетной политике (FIFO), определенной в договоре ДУ
- Обеспечивается учет следующих операций с денежными средствами и ценными бумагами
  - Ввод/вывод доли учредителя
  - Учет расходов по операциям с ЦБ
  - Объединение выпусков ЦБ в портфеле ДУ
  - Отражение затрат управляющего
  - Удержание вознаграждения управляющего
- Формирование регистров внутреннего учета:
  - Регистр внутреннего учета сделок с ценными бумагами
  - Регистр внутреннего учета денежных средств
  - Регистр внутреннего учета ценных бумаг
