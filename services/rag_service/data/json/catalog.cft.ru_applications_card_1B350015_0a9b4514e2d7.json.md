## Описание

## Предлагайте клиентам цифровые карты для мобильных устройств.

Приложение позволяет управлять процессом оформления банковской карты без пластикового носителя. Пластиковый носитель заменяется мобильным устройством с возможностью бесконтактной оплаты. При оформлении карты клиенту на мобильный телефон будут отправлены реквизиты для совершения операций по карте. Приложение позволяет активировать карту в режиме реального времени при обращении клиента.
Используя Приложение банк снизит расходы на изготовление пластиковых карт, сократит время обслуживания клиентов и сможет перейти на дистанционную выдачу карт.

## Функциональные возможности

- Регистрация пула цифровых карт в процессинговом центре для оперативного оформления клиенту
- Оформление дополнительной банковской карты с пластиковым носителем
- Автоматическое формирование и выгрузка сообщений в процессинговый центр для определения карты к выдаче клиенту и активации карты средствами универсального шлюза "Интегратор"
- Автоматическое извлечение ответных сообщений средствами универсального шлюза "Интегратор"
- Разбор ответных сообщений в соответствии с поставляемыми форматами с данными по выдаваемой цифровой карте и ее активации в процессинговом центре
