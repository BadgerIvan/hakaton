## Контроль использования доверенностей при обслуживании клиента.

Приложение позволяет регистрировать доверенности клиентов и контролировать возможность предоставления услуг доверенному лицу клиента.

## Функциональные возможности

- Регистрация доверенности
- Автоматический контроль возможности проведения операции по доверенности
- Блокировка/разблокировка доверенности
- Учет разовых доверенностей
