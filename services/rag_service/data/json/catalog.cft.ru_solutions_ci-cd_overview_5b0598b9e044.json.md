# ЦФТ-CI/CD (Платформа развития)

## Краткое описание

Предлагаем использовать технологии АО «ЦФТ» для организации процесса CI/CD в части развития и сопровождения любой Системы на базе Платформы ЦФТ

## Описание

Предлагаем использовать наработки и технологии АО «ЦФТ» для организации процесса CI/CD в части развития и сопровождения любой Системы на базе Платформы ЦФТ.

Переход на современную технологию производства CI/CD с использованием нового поколения среды разработки [ЦФТ - Интегрированная среда разработки](https://catalog.cft.ru/applications/card/IDE) и системы управления версиями GitLab позволит:

- Сократить продолжительность разработки и внедрения необходимых изменений/исправлений.
- Снизить риски внедрения изменений/исправлений за счет замещения ручного труда и автоматизации проверки, тестирования, передачи и установки поставок.
- Убрать временной разрыв между разработкой и пользовательским тестированием.
- За счет оптимизации процессов получить возможность равномерного распределения релизов по времени, для уменьшения их объема и сокращения времени простоя Системы.
- Повысить качество ПО и минимизировать операционные риски.
- Передать контроль за изменениями, устанавливаемыми на промышленную среду Системы на базе Платформы ЦФТ, уполномоченным сотрудникам.
- Внедрить процедуры автоматизированного тестирования изменений и снизить риск установки на промышленную среду поставок ПО, ухудшающих производительность и быстродействие Системы на базе Платформы ЦФТ.
- Организовать единую среду разработки, исключающую конфликты разработки еще на этапе написания исходного кода.
- Организовать рефакторинг исходного кода поставок.
- Обеспечить фиксацию и хранение истории изменений исходного кода.

ЦФТ-CI/CD предназначен для поддержки процесса непрерывной разработки и доставки изменений продуктов на базе Платформы ЦФТ, подразумевает хранение исходного кода в GIT и использование [ЦФТ - Интегрированная среда разработки](https://catalog.cft.ru/applications/card/IDE) в качестве инструмента разработки продуктов.

CI/CD построено на базе технологии GitLab CI с использованием собственных приложений и сервисов, а также Open Source и бесплатных версий лицензионных сервисов для выполнения соответствующих задач комплекса.

Все цены приведены без учета НДС. НДС рассчитывается согласно действующему законодательству РФ. Цены не включают стоимости лицензии на использование ПО третьих лиц (например, СУБД).
