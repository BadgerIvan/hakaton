## Сократите затраты на расчет и удержание комиссий за услуги по картам.

Приложение предназначено для автоматического взимания комиссий за оказание услуг по картам ПЦ UCS. Приложение позволяет планировать комиссионные платежи, формировать документы бухгалтерского учета по удержанию комиссий, вести учет задолженности и погашать возникшие задолженности при поступлении средств на счет клиента без привлечения сотрудников банка.

## Функциональные возможности

- Оплата комиссий:

- За годовое обслуживание карты
- За предоставление услуги SMS-информирования по карте

- Взимание комиссионного вознаграждения за оказание услуг согласно установленным тарифам с определением:

- Периодичности и даты взимания комиссии за очередной период пользования услугой
- Льготного периода пользования услугой после первого ее подключения
- Периода ожидания оплаты при недостаточности средств на счете клиента в дату взимания комиссии до отключения услуги/блокировки карты
- Очередной даты взимания комиссии с учетом собственных условий банка

- Автоматическое формирование документов по оплате комиссий
- Расчет следующей даты оплаты в зависимости от:

- Фактической даты оплаты
- Предыдущей плановой даты

- Возможность выбора счета клиента для проведения плановых оплат комиссии
- Приостановка SMS-информирования/блокировка карты:

- при недостаточности средств для оплаты
- по окончании периода ожидания оплаты

- Возобновление SMS-информирования после погашения всех задолженностей
- Автоматическое погашение задолженности по комиссии при поступлении средств на счет клиента
- Отложенное подключение услуги SMS-информирования при недостаточности средств (отправка запроса на подключение услуги в ПЦ только после оплаты услуги)
- Взимание платы за услуги за несколько периодов вперед (по инициативе клиента)
