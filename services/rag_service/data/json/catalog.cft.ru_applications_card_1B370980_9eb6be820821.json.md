## Описание

## Учет сделок по факторингу с использованием механизма зачета взаимных требований между Банком и Клиентом.

Приложение обеспечивает ведение учета факторинговых сделок при построении бизнес-процесса факторингового обслуживания на основе использования механизма зачета взаимных требований между банком и клиентом.

## Функциональные возможности

- Возможность погашения задолженностей клиента перед банком за счет уменьшения суммы обязательств Банка перед клиентом.
- Формирование бухгалтерских документов при погашении задолженности путем зачета взаимных требований.
- Возможность указания задолженности, которая будет погашена за счет уменьшения суммы финансирования, перечисляемой клиенту.
