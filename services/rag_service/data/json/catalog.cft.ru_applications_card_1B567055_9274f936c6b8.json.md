## Описание

## Формирование сообщений по внебиржевым конверсионным сделкам (не ПФИ), заключенным вне рамок генерального соглашения, для отправки в репозитарий.

Приложение позволяет автоматизировать процесс обмена данными с репозитарием по внебиржевым конверсионным сделкам (не ПФИ) с отсрочкой исполнения, заключенным вне рамок генерального соглашения. Для формирования сообщений используется актуальная информация, содержащаяся в реестре конверсионных операций. Приложение оптимизирует работу сотрудников при подготовке информации для репозитария.

## Функциональные возможности

- Формирование сообщений по внебиржевым конверсионным сделкам (не ПФИ) с отсрочкой исполнения, заключенным вне рамок генерального соглашения:

- Сообщение о регистрации/изменении/исполнении сделки
- Подтверждение/отказ на запрос о согласовании анкеты
- Отчет о расчете справедливой (оценочной) стоимости

- Обработка входящих сообщений от репозитария:

- Извещение о регистрации, отказе в исполнении/регистрации
- Уведомление о статусе анкеты сделки, о расхождениях в условиях анкет
- Запрос на согласование анкеты

- Формирование FpML-файлов для их дальнейшей передачи в репозитарий
- Контроль полноты и сроков предоставления информации для репозитария
- Хранение истории сообщений
