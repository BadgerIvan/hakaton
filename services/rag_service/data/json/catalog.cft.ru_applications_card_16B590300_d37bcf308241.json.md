## Расчет доходов и расходов по контрактам с опционами на фьючерс в целях определения налоговой базы.

Приложение позволяет рассчитать доходы и расходы, получаемые от сделок с опционами на фьючерс с базовыми активами - валюта, драгоценный металл, процентная ставка, индекс, товар, эмиссионные ценные бумаги. Данные сохраняются в аналитической таблице в виде, удобном для их контроля.

## Функциональные возможности

- Формирование аналитической таблицы по данным о доходах и расходах по сделкам с опционом на фьючерс
