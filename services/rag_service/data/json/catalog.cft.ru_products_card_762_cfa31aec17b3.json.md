## Примеры настройки продукта из каталога

Это параметры примера настройки, а не условия конкретного банка.

## Настройка 1

Выкупаемые кредиты - кредиты частным лицам с единоразовой выдачей

## Пример 1

"Договоры покупки/продажи кредитов" > "Вид договора" - "Договор покупки", "Класс договоров" - "Кредиты частным лицам", "Выкупленные/проданные договоры".

## Настройка 2

"Договоры покупки/продажи кредитов" > "Валюта"

## Настройка 3

Покупка кредитов без отсрочки платежа

## Пример 3

"Договоры покупки/продажи кредитов" > операция "Добавить" > "Дата оплаты" не заполняется
