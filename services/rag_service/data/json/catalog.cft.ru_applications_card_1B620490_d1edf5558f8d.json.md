## Функциональные возможности

- Расчет показателей отчета по остаткам и оборотам по балансовым счетам.
- Возможность выделения оборотов СПОД.
- Возможность отображения итогов по балансовым счетам второго порядка.
- Возможность исключения строк с нулевыми данными из отчета.
- Возможность вывода в отчете данных по отдельным главам Плана счетов.
- Получение отчета по данным архива учетных счетов в валютах подразделения.
- Получение сводного отчета или отчета по филиалу.
- Формирование отчета в формате OOXML.
