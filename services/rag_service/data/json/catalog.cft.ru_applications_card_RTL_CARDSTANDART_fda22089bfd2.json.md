## Функциональные возможности

1. Виды обрабатываемых файлов:

- форматы файлов с запросами на управление картами (BTRT; BTRT Срочные);
- форматы файла-ответа на запросы по управлению картами (успешные/неуспешные, OIA файл);
- формат файла-ответа на запрос по списку выпущенных карт (OCI файл);
- форматы файлов с запросами на изменение Лимита Авторизации (IBI файл);
- формат файла-ответа на запросы на изменение Лимита Авторизации (OBR файл);
- формат файла балансов по карт-счетам;
- формат файлов с транзакциями по эмиссии (OBI файл);
- формат файлов с транзакциями по эквайрингу (OBM файл);

2. Функциональные особенности:

- Выгрузка исходящих балансов для установки лимита авторизации в процессинге;
- Блокировка или закрытие перевыпускаемой карты при выдаче перевыпущенной карты Клиенту;
- Использование параметров карточного продукта/карты, определяющих ограничения в обслуживании карты;
- Сверка лимитов авторизации в ПЦ и Системе;
- Блокировка карт при выпуске и разблокировка их при выдаче Клиентам.
