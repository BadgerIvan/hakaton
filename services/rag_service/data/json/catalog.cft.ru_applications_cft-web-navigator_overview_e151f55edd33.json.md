# ЦФТ Веб-Навигатор

## Краткое описание

Универсальное рабочее место пользователя, позволяющее просматривать экземпляры и выполнять операции согласно информационной модели и правам доступа

## Описание

ЦФТ Веб-Навигатор является универсальным рабочим местом пользователя,
которое позволяет просматривать Экземпляры Типов Базовых Понятий (ТБП) и
выполнять операции в соответствии с информационной моделью и правами доступа.

ЦФТ Веб-Навигатор позволяет пользователю выполнять навигацию в рамках
информационной модели системы
“ЦФТ–Банк” (а также других систем, созданных на аналогичной платформе) посредством взаимодействия с Яндекс
браузером или любым другим современным, поддерживающим ES5 стандарт (IE8 и более ранние версии не поддерживаются).

Все цены приведены без учета НДС. НДС рассчитывается согласно действующему законодательству РФ. Цены не включают стоимости лицензии на использование ПО третьих лиц (например, СУБД).
