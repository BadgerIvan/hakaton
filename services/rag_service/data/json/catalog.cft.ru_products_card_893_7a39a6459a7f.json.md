# Внутренний учет операций банка с ПФИ на драгметаллы, совершенных через внешнего брокера 

**Каталог:** ЦФТ-Банк

**Код продукта:** 04221330027

**Направление продукта:** Операции банка

**Группа:** Инвестиции и ценные бумаги

**Подгруппа:** Внутренний учет по Постановлению ФКЦБ № 32

## Краткое описание

Внутренний учет сделок банка с производными финансовыми инструментами на драгоценный металл, совершенных через внешнего брокера

**Необходимые приложения (коды):**  1B010010, 1B010020, 1B010030, 1B010040, 1B010060, 1B010090, 1B565270, 1B530270, 1B565280, 1B565290, 1B530320, 1B530430

**Рекомендуемые приложения (коды):**  1B010610

## Примеры настройки продукта из каталога

Это параметры примера настройки, а не условия конкретного банка.

## Настройка 1

Внутренний учет по Постановлению ФКЦБ № 32

## Пример 1

"Настройки." > "Код" равно "EXISTS\_SVU", "Общее значение" равно "ДА"

## Настройка 2

Категории ПФИ, по которым формируются документы СВУ

## Пример 2

"Настройки. (Срочный рынок)" > "Код" равно "DM\_CATEGORY\_SVU", "Общее значение" равно "ДА" > "Значение настройки" > "Значение" равно "Да" > операция "Изменить" > "СР Категории ПФИ" равно "пустому"

## Настройка 3

Категории ПФИ для отражения в регистрах СВУ

## Пример 3

"Настройки. (Срочный рынок)" > "Код" равно "DM\_SVU\_CATEGORY\_PRINT", "Общее значение" равно "ДА" > "Значение настройки" > "Значение" равно "Да" > операция "Изменить" > СР Категории ПФИ" равно "пустому"

## Настройка 4

Сделки покупки/продажи с ПФИ на драгоценные металл, заключенных через внешнего брокера

## Пример 4

"Реестр сделок с ПФИ " > операция "Изменить" > закладка "Основная" > "Торговая площадка", "Вид сделки", "Тип сделки", "Подтверждающий документ", "Договор получения услуг", "СВУ Аналитический счет"
