## Описание

## Оптимизируйте процесс ввода информации по договорам банковской гарантии за счёт быстрой и удобной конвертации данных.

Используйте Приложение для импорта договоров банковской гарантии при миграции данных из внешней системы учета. Автоматизированная процедура загрузки данных позволяет не допустить возникновения ошибок, неизбежных при ручном вводе, а также сократить затраты времени на ввод и проверку информации.

## Функциональные возможности

- Импорт договоров банковской гарантии и связанных данных (счетов, плановых и фактических операций, истории категории качества, схем начисления процентов, журналов начисленных процентов и т.д.), с возможностью загрузки исторических данных частями по мере их подготовки к импорту
- Проверка корректности формата, подготовленного файла импорта
- Исключение дублирования записей при повторном импорте
- Удаление данных
