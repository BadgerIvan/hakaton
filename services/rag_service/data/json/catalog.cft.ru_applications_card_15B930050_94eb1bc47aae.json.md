## Описание

## Учет мошеннических операций по картам на счетах незавершенных расчетов.

Приложение позволяет банку по определенным правилам отбора выявлять подозрительные (мошеннические) операции по картами осуществлять расчет по ним с платежными системами со счетов незавершенных расчетов, а не с карточных счетов клиентов. При помощи самостоятельно разработанных алгоритмов Банк сможет выделить подозрительные операции из общего реестра транзакций и вести учет таких операций на специально открытых лицевых счетах для дополнительного контроля и подтверждения легальности совершения операции. Используя данное Приложение, банк сможет оперативно реагировать на выявленные случаи мошенничества, что позволит снизить потери от возможных убытков и повысить лояльность клиентов, предоставляя защищенный сервис.

## Функциональные возможности

- Настройка правил отбора подозрительных транзакций
- Автоматическая проверка транзакций при их обработке в соответствии с настроенными правилами
- E-mail уведомление ответственных сотрудников при обнаружении подозрительной транзакции
- Ведение журнала учета подозрительных транзакций
- Учет сумм подозрительных транзакций на счетах требований/обязательств по незавершенным расчетам
- Формирование запроса в ПЦ на изменение лимита авторизации на сумму подозрительной транзакции
- Блокировка, разблокировка и подтверждение операций
