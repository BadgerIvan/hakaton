# Договор зачисления заработной платы на счета по вкладам

**Каталог:** ЦФТ-Банк

**Код продукта:** 0201460001

**Направление продукта:** Корпоративным клиентам

**Группа:** Банковские карты

**Подгруппа:** Зарплатные проекты

## Краткое описание

Выплата заработной платы сотрудникам предприятия (организации) на счета по вкладам

**Необходимые приложения (коды):**  1B010010, 1B400010, 1B410010, 1B410020, 1B400020, 1B010020, 1B010030, 1B410030, 1B010040, 1B400060, 1B010060, 1B010090, 1B400290, 1B410031, 1B410100, 1B410036, 1B410025

**Рекомендуемые приложения (коды):**  1B620030, 1B620080, 1B620100, 1B620150, 1B770010, 1B770020, 1B620274, 1B620243, 1B770030, 1B770015, 1B770017, 1B770050, 1B410037

## Примеры настройки продукта из каталога

Это параметры примера настройки, а не условия конкретного банка.

## Настройка 1

Открытие специальных счетов "до востребования" сотрудникам организации

## Пример 1

"Депозиты и ПК. Зарплатный проект" операция "Изменить" - > "Виды депозитных договоров" - > "Виды депозитного договора" операция "Изменить". "Депозиты и ПК. Зарплатный проект" - > "История приема файлов" для реестра формата "(1) Открытие досье" - > "Реестр" поле "Номер счета".

## Настройка 2

Формат реестра предоставляемого организацией на открытие счетов

- Файл MS Excel
- Поля реестра: фамилия, имя, отчество, резидент, код пола клиента, дата рождения, инн, место рождения, гражданство, адрес регистрации, дополнительный адрес, код типа документа, серия документа, номер удостоверения, дата выдачи документа, кем выдан, дата окончания, код подразделения, телефон, кодовое слово

## Пример 2

"Депозиты и ПК. Зарплатный проект" операция "Изменить" - > "Файловые маски форматов" - > для экземпляра "(1) Открытие досье" - > "Формат" - > операция "Изменить" - > "Поля реестра" и "Набор правил".

## Настройка 3

Формат реестра предоставляемого организацией на зачисление денежных средств сотрудникам предприятия

- Файл MS Excel
- Поля реестра: номер счета, сумма

## Пример 3

"Депозиты и ПК. Зарплатный проект" операция "Изменить" - > "Файловые маски форматов" - > для экземпляра "(1) Зачисление" - > "Формат" - > операция "Изменить" - > "Поля реестра" и "Набор правил"
