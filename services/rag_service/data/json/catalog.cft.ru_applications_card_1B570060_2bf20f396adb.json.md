## Организуйте учет служебных командировок сотрудников.

Приложение предназначено для подготовки документов на командировки сотрудников и отражения их в табелях учета рабочего времени

## Функциональные возможности

- Оформление командировок и печать приказов на них
- Отражение командировок в табеле учета рабочего времени
- Изменение и отмена командировок с печатью соответствующих приказов
- Печать журнала учета командировок
- Печать служебных заданий и командировочных удостоверений по унифицированным формам (Т-10 и Т-10а)
