## Описание

## Сократите трудозатраты при постановке прав требований по пулу кредитов на учет.

Приложение обеспечивает возможность постановки на учет пула кредитов с отсрочкой платежа, позволяет контролировать поступление оплаты по договору покупки.

## Функциональные возможности

- Расчет номинальной стоимости пула (для кредитов с историей операций)
- Постановка на учет приобретенных прав требований по пулу кредитов
- Формирование документов на отражение обязательств по оплате пула
- Получение и отражение оплаты по пулу:

- Контроль за исполнением обязательств по оплате
- Отражение оплаты и формирование документов по исполнению обязательств
