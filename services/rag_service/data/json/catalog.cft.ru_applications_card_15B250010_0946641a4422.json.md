## Настройка экспорта и импорта платежных документов.

Приложение предназначено для организации импорта и экспорта информации о платежных документах. Автоматизированное формирование и проводка документов на основе импортированных записей позволит банку сократить время на ручной ввод документов.

## Функциональные возможности

- Настройка параметров экспорта и импорта документов
- Экспорт документов:

- В текстовый файл формата csv
- В АБС IBSO (посредством Oracle db-link)
- На принтер и/или в текстовый файл в виде печатных форм

- Экспорт документов по всем филиалам / по филиалу или отделению пользователя
- Просмотр и редактирование исходящих документов
- Подсчет суммы и количества исходящих документов
- Формирование сводных исходящих документов по выбранным параметрам
- Импорт документов:

- Из текстового файла формата csv
- Из АБС IBSO (посредством Oracle db-link)

- Просмотр и корректировка импортированных данных
- Автоматическое формирование и проводка внутренних документов на основании импортируемых данных
- Учет операционного дня импортируемых документов
