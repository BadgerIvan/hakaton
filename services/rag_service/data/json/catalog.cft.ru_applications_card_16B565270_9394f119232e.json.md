## Краткое описание

## Описание

## Учет собственных сделок с фьючерсными контрактами на драгметаллы, заключенных организацией через внешнего брокера.

Несложное в использовании Приложение позволит сократить время на обслуживание сделок, заключенных на торговых площадках через внешнего брокера, их отражение в учете, а также позволит избежать ошибок в расчетах. Приложение не только существенно упрощает процедуру бухгалтерского учета сделок, автоматически формируя документы по открытию, переоценке и закрытию обязательств/требований по главе Г, но и позволяет учесть особенности договора организации с внешним брокером.

## Функциональные возможности

- Регистрация договоров с внешними брокерами, через которых заключаются срочные сделки
- Ведение реестра фьючерсных контрактов на драгметаллы, которые заключены организацией через внешнего брокера
- Импорт биржевой информации о сделках и позициях с ПФИ (из файла внутреннего формата)
- Обработка биржевой информации о сделках с ПФИ (полученной из файла внутреннего формата)
- Импорт биржевой информации о котировках ПФИ (из файла внутреннего формата)
- Учет сделок покупки, продажи фьючерсов на драгметаллы
- Учет вариационной маржи и комиссионных сборов
- Учет операций по переводам/возвратам денежных средств брокеру/от брокера
- Открытие, переоценка и закрытие (в т.ч. взаимозачет по методу FIFO) обязательств/требований на главе Г по срочным сделкам
- Ведение позиции по контракту
