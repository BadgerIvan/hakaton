## Описание

## Учет брокерских биржевых сделок с ценными бумагами в условиях значительных объемов проводимых сделок.

Приложение позволяет в ускоренном режиме обрабатывать сделки купли/продажи эмиссионных ценных бумаг, инвестиционных паев (кроме сделок РЕПО), совершенных банком для клиентов по договорам на брокерское обслуживание. Приложение осуществляет предварительную обработку сделок, сбор и хранение информации, необходимой для последующего формирования финансовых документов. Возможности Приложения позволят использовать алгоритмическую поддержку в торговле, осуществлять ведение брокерских биржевых сделок с ценными бумагами в режиме автоматического трейдинга. Использование Приложения возможно только совместно с Приложением "Импорт данных по сделкам с ценными бумагами на основном рынке Московской биржи" и Приложениями по учету брокерских биржевых сделок с ценными бумагами, представленных в разделах данного Каталога "Эмиссионные ценные бумаги", "Инвестиционные паи".

## Функциональные возможности

- Формирование данных по брокерским биржевым сделкам купли/продажи ЭЦБ, инвестиционных паев (кроме сделок РЕПО) для осуществления ускоренной обработки сделок
- Предварительная обработка и хранение данных сделок купли/продажи ЭЦБ, инвестиционных паев (кроме сделок РЕПО) (вне зависимости от объема проводимых сделок) для последующего формирования учетных документов
