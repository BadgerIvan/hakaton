## Импорт и обработка информации о результатах торгов на секции срочного рынка FORTS.

Приложение обеспечивает возможность импортировать и обрабатывать биржевую информацию о сделках с опционами на фьючерс (в т.ч. маржируемыми), вариационной марже по сделкам и по входящей позиции, а также о котировках фьючерсных контрактов, являющихся базовым активом опционов, заключенных в рамках дилерской и/или брокерской деятельности Банка на секции FORTS торговой площадки группы "Московская биржа". Автоматизированная процедура загрузки данных позволяет избежать возникновения ошибок, возможных при ручном вводе, а также сократить затраты времени на ввод и проверку данных.

## Функциональные возможности

- Импорт биржевой информации о сделках с опционами на фьючерс банка и его клиентов по договорам на брокерское обслуживание (из файла формата o04\_XXYY.csv)
- Проверка полноты и корректности информации в системе, необходимой для обработки опционных сделок банка и его клиентов по договорам на брокерское обслуживание
- Обработка биржевой информации о сделках с опционами на фьючерс банка и его клиентов по договорам на брокерское обслуживание (полученной из файла формата o04\_XXYY.csv)
- Автоматическое формирование собственных и/или клиентских сделок с ПФИ по итогам обработки биржевой информации о сделках с опционами на фьючерс (полученной из файла формата o04\_XXYY.csv)
- Импорт биржевой информации о вариационной марже по входящей позиции по опционным контрактам банка и его клиентов по договорам на брокерское обслуживание (из файла формата oposXXYY.csv)
- Импорт биржевой информации о котировках фьючерсных контрактов, являющихся базовым активом опционов (из файла формата f07.csv)
- Импорт биржевой информации о денежном состоянии банка и его клиентов по договорам на брокерское обслуживание (из файла формата monXXYY.csv)
- Импорт биржевой информации об иностранной валюте и ценных бумагах, предоставленных в качестве средств гарантийного обеспечения банком и его клиентами по договорам на брокерское обслуживание (из файла формата moncbXXYY.csv)
