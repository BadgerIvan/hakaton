## Описание

## Сопряжение с системами кредитования сторонних производителей.

Сопряжение подсистемы Кредиты с внешними системами выполняется посредством обмена файлов в XML- формате между внешней системой и АБС. Приложение решает задачи интеграции различных фронт-офисных систем с АБС и предоставляет возможность взаимодействовать с точками выдачи кредитов в рамках POS-кредитования.

## Функциональные возможности

- Выполнение следующих операций на основании XML-запросов из внешних систем:

- Регистрация досье заемщика
- Открытие кредитного договора (счета), картсчета (при оформлении карточного кредита)
- Открытие договоров обеспечения
- Расчет графика погашения
- Формирование и проводка платежных документов на выдачу кредита и уплату комиссий
- Регистрация информации об объектах залога
- Регистрацию информации по договорам страхования

- Контроль подтверждения выдачи кредита в течение заданного периода (в часах), с возможностью автоматического отклонения запроса на оформление кредита по истечении данного периода
- Передача ответных сообщений во внешнюю систему с информацией об открытых счетах, графиках погашения, сформированных документах
- Предоставление информации о задолженности по договору по запросу из внешней системы
