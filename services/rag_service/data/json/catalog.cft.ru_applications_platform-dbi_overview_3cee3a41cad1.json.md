# ЦФТ-Платформа DBI

## Краткое описание

Среда исполнения бизнес-приложений с высокой транзакционной нагрузкой, которые разработаны с использованием языка программирования PL+

## Описание

Программный комплекс «ЦФТ-Платформа DBI» (далее – «Система») - это среда исполнения бизнес-приложений с высокой транзакционной нагрузкой, которые разработаны с использованием языка программирования PL+. Кроме того, Система обеспечивает взаимодействие с базой данных, администрирование пользователей и управление доступом к информационным ресурсам бизнес-приложений.

Система используется для запуска корпоративных приложений, в которых важна надежность, безопасность и согласованность данных. Все ключевые компоненты приложения – структура данных, интерфейсы, бизнес-операции и правила доступа – описываются в рамках единой информационной модели, что упрощает сопровождение и повышает устойчивость решений. Система поддерживает работу с рядом реляционных СУБД (включая PostgreSQL), позволяет подключаться пользователям при помощи веб-клиента и обеспечивает интеграцию по стандартным протоколам.

Данное описание решения приведено для предварительного ознакомления с функциональностью Системы и может не содержать исчерпывающий список условий и ограничений. Точные характеристики Системы отражены в сопроводительной документации.

Все цены приведены без учета НДС. НДС рассчитывается согласно действующему законодательству РФ. Цены не включают стоимости лицензии на использование ПО третьих лиц (например, СУБД).
