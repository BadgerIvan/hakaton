## Краткое описание

Предоставьте клиентам возможность без визита в банк направлять заявку на оформление договора РКО с резервированием номера для расчетного счета

## Описание

## Предоставьте клиентам возможность без визита в банк направлять заявку на оформление договора РКО с резервированием номера для расчетного счета.

Приложение предназначено для организации процесса удаленного резервирования номера счета РКО для юридических лиц и индивидуальных предпринимателей по запросу от внешней системы. В приложении автоматизированы проверки потенциального клиента и резервирование номера расчетного счета. Использование приложения позволит повысить количество и лояльность клиентов, а также сократить временные затраты сотрудников банка на последующую идентификацию и проверку клиентских данных.

## Функциональные возможности

- Проверка наличия подходящего клиента в системе
- Создание досье клиента в составе реквизитов, необходимых для резервирования номера счета РКО
- Проверка клиента (функция реализуется с помощью дополнительно лицензируемых приложений):

- По спискам противодействия легализации
- На банкротство по данным ЕФРСБ
- На наличие приостановлений по счетам по данным ФНС
- На наличие приостановлений по счетам по данным ФТС

- Возможность настройки необходимости и жесткости проверок реквизитов создаваемого досье клиента
- Предварительное создание договора РКО с резервированием номера расчетного счета
- Работа с запросами по приему клиента на обслуживание:

- Автоматическая обработка запросов, полученных из внешней системы
- Автоматическое принятие решения по клиенту и отправка ответа во внешнюю систему
- Постановка запроса на ручной контроль в ситуациях, требующих участия пользователя
