# Отнесение доходов/расходов при урегулировании резервов по кредитному договору на любой филиал банка

**Каталог:** ЦФТ-Банк

**Направление продукта:** Операции банка

**Группа:** Кредитование

## Краткое описание

Распределение доходов/расходов по формированию резервов в филиальной сети банка.

**Необходимые приложения (коды):**  1B010010, 1B010020, 1B290030, 1B010030, 1B100030, 1B010040, 1B010050, 1B290040, 1B290050, 1B010060, 1B290080, 1B010090, 1B290085, 1B290090, 1B290100, 1B290110, 1B290120, 1B290130, 1B010130, 1B290140, 1B290150, 1B010150, 1B290160, 1B290200, 1B290210, 1B290212, 1B290218, 1B290220, 1B290230, 1B290240, 1B290250, 1B290260, 1B290190, 1B010270, 1B290105, 1B290076, 1B290214, 1B290216, 1B290084, 1B290380

**Рекомендуемые приложения (коды):**  1B100020, 1B010140, 1B290960

## Примеры настройки продукта из каталога

Это параметры примера настройки, а не условия конкретного банка.

## Настройка 1

Настройка филиала для формирования доходов\расходов при урегулировании резервов по кредитному договору

## Пример 1

"Настройки. Значения" > операция "Изменить" > "Подразделения" равно "Главное подразделение">"MetaClass" равно "Кредиты частным лица">"Филиалы" равно "Новосибирский филиал Модельного банка"

## Настройка 2

Настройка филиала для формирования доходов\расходов при урегулировании резервов по продукту "Резервирование"

## Пример 2

"Настройки. Значения" > операция "Изменить" > "Подразделения" равно "Главное подразделение" > "MetaClass" равно "Резервирование" > "Филиалы" равно "Новосибирский филиал Модельного банка"

## Настройка 3

Выбор филиала для формирования доходов\расходов при урегулировании резервов по кредитному договору

## Пример 3

"Кредиты частным лицам" > операция "Редактировать договор" > закладка "Дополнительно" > установлен флаг "Филиал из настройки "RES\_IN\_OTHER\_FILIAL"

## Настройка 4

Выбор филиала для формирования доходов\расходов при урегулировании резервов по продукту "Резервирование"

## Пример 4

"Резервирование" > операция "Изменить" > установлен флаг "Филиал из настройки "RES\_IN\_OTHER\_FILIAL"
