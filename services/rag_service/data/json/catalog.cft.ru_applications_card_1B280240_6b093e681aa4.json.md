## Возможность предоставления клиентам отсрочки платежей по комиссиям за обслуживание аккредитивов.

Приложение предназначено для ведения комиссий за обслуживание аккредитивов с отсрочкой платежа. Использование приложения позволит сформировать графики начислений и платежей по комиссиям с учетом отсрочки, исполнить плановые операции данных графиков с созданием соответствующих платежных документов.

## Функциональные возможности

- Создание правил начисления комиссий при регистрации тарифных планов и/или индивидуальных тарифов на аккредитивах:
- с заданной периодичностью
- единоразово за весь период взимания комиссии
- Настройка количества дней отсрочки платежей по комиссиям при регистрации тарифных планов и/или индивидуальных тарифов на аккредитивах
- Автоматическое построение графиков:
- начисления комиссий
- платежей по комиссиям с учетом дней отсрочки
- Начисление комиссий по аккредитивам с автоматическим формированием и обработкой платежных документов/финансовых распоряжений
