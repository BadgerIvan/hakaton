# Депозитарий

## Краткое описание

Решение представляет собой современный функциональный комплекс для оказания услуг при выполнении депозитарной деятельности

## Описание

Решение представляет собой современный функциональный комплекс для оказания услуг при выполнении депозитарной деятельности.

Депозитарий ЦФТ-Банк реализован в соответствии с требованиями нормативных документов:

- Федеральный закон от 22.04.1996 № 39-ФЗ «О рынке ценных бумаг»,
- Положение Банка России от 13.11.2015 № 503-П «О порядке открытия и ведения счетов депо и иных счетов»,
- Положение Банка России от 13.05.2016 №542-П «О требованиях к осуществлению депозитарной деятельности при оформлении записей на основании документов, относящихся к ведению депозитарного учета, а также документов, связанных с учетом и переходом прав на ценные бумаги, и при хранении указанных документов»,
- Базовый стандарт совершения депозитариев операций на финансовом рынке, согласованный с Комитетом по стандартам по депозитарной деятельности,
- Иные регуляторные акты, регламентирующие проведения различных процедур, осуществляемых при выполнении депозитарной деятельности.

Функциональные возможности Депозитария ЦФТ-банк позволяют решать следующие задачи:

1. Вести базу финансовых инструментов для депозитарного учета, обновлять информацию с использованием сервиса API NSD и других внешних источников.
2. Вести договоры счетов депо, открывать счета депо и разделы для клиентов юридических и физических лиц, а также в целях учета ценных бумаг банка.
3. Вести раздельный депозитарный и количественный учет ценных бумаг на основе единых функциональных продуктов.
4. Рассчитывать и удерживать комиссию за депозитарные услуги с клиентов с учетом тарифов банка и вышестоящего депозитария.
5. Производить сверку с расчетными депозитариями бирж.
6. Осуществлять раскрытие списка депонентов - владельцев ценных бумаг для исполнения корпоративных действий, выплачивать доходы по ценным бумагам, рассчитывать и удерживать налог на доходы с физических лиц при выплате доходов по ценным бумагам.
7. Собирать консолидированную обязательную отчетность для регулятора.
8. Получать аналитические данные, используя возможности учетной системы.
9. Осуществлять депозитарную деятельность в нескольких филиалах банка с отражением в единой консолидированной отчетности.
10. Обеспечить защиту и хранение данных депозитарного учета.

Данное решение отвечает всем требованиям регулятора, позволяет настроить систему под требования регламента депозитария, наращивать и развивать функциональные возможности.

Все цены приведены без учета НДС. НДС рассчитывается согласно действующему законодательству РФ. Цены не включают стоимости лицензии на использование ПО третьих лиц (например, СУБД).
