## Краткое описание

Исполнение неттинга по выбранному набору сделок клиентов по договору на брокерское обслуживание покупки-продажи эмиссионных ценных бумаг

## Описание

## Исполнение неттинга по выбранному набору сделок клиентов по договору на брокерское обслуживание купли-продажи эмиссионных ценных бумаг.

Приложение обеспечит регистрацию в системе соглашений о неттинге и автоматическое формирование финансовых документов и документов внутреннего учета по взаимозачету однородных требований  и обязательств по списку брокерских сделок купли-продажи эмиссионных ценных бумаг, в том числе с доплатой с любой стороны. Пользователю предлагается удобный интерфейс и большое количество проверок различного уровня жесткости для минимизации ошибок ручного ввода. Дополнительно Вы получаете возможность сочетания с любым из Приложений неттинга для обеспечения взаимозачета по денежным средствам между различными видами сделок и по ценным бумагам по брокерским сделкам с ЭЦБ.

## Функциональные возможности

- Регистрация в системе соглашений по неттингу денежных средств
- Фиксация списка внебиржевых сделок клиента купли-продажи эмиссионных ценных бумаг, включенных в неттинг, в том числе и с доплатой с любой стороны
- Контроль условий и блокирование от возможности оплаты вне неттинга
- Формирование бухгалтерских документов и документов СВУ, отражающих выполнение расчетов взаимозачетом  по сделкам клиента купли-продажи эмиссионных ценных бумаг по денежным средствам в одной валюте с одним контрагентом, а также документов доплат

Дополнительно, при наличии соответствующего продукта неттинга, продукт выполняет взаимозачет денежных средств:

- Одной из частей сделок РЕПО со сделками купли-продажи эмиссионных ценных бумаг

Дополнительно, при наличии функционала «Неттинг по ценным бумагам по брокерским сделкам с ЭЦБ», продукт выполняет взаимозачет бумаг по сделкам клиента с ЭЦБ
