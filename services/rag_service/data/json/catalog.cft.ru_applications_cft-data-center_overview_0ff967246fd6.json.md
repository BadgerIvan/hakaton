# ЦФТ-Центр подготовки данных

## Краткое описание

Агрегация и обогащение данных, полученных из гетерогенных источников с целью дальнейшего анализа и интеграции с внешними системами

## Описание

Программный комплекс «ЦФТ-Центр подготовки данных» предназначен для сбора и аналитической обработки данных, полученных из учетной системы с целью организации информационного обмена с внешними системами. В качестве учётной системы могут выступать любые АБС, хранилища данных и другие источники, при условии соблюдения установленного формата (API) взаимодействия с программным комплексом.

Программный комплекс предоставляет возможности обогащения полученных данных на основе правил и справочной информации и выполнения форматно-логического контроля в соответствии с заданными критериями и правилами.

С использованием механизма интеграции, на основе полученных наборов данных, комплекс реализует информационный обмен с внешними системами в соответствии с требованиями этих систем.

Программный комплекс представляет собой самостоятельное решение, которое может быть использовано для различных бизнес-задач.

Все цены приведены без учета НДС. НДС рассчитывается согласно действующему законодательству РФ. Цены не включают стоимости лицензии на использование ПО третьих лиц (например, СУБД).
