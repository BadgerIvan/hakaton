# Централизованное управление ликвидностью

## Краткое описание

Готовое решение для информационной поддержки казначейской функции по управлению ликвидностью группы организаций

## Описание

Готовое решение для информационной поддержки казначейской функции по управлению ликвидностью группы организаций.

Решение обеспечивает специалистов единого казначейства группы полной информацией о плановых и фактических операциях по сделкам внешнего привлечения и размещения, внутригруппового заимствования, документарных операциях, сделках с ценными бумагами.

Возможности:

- Централизованное согласование заявок организаций на приобретение банковских продуктов с автоматическим контролем лимита риска на кредитную организацию
- Автоматический расчёт плановых операций сделок внешнего размещения и привлечения в соответствии с условиями договоров, учёт фактического их исполнения
- Автоматизация двустороннего учёта плановых и фактических операций по договорам внутригруппового заимствования: учёт ведется и для организации-заёмщика, и для организации-заимодавца
- Ежедневный учёт задолженности и расчёт процентов за использование заемных средств пул-лидером перед организациями-участниками договора банковского кэш-пулинга
- Формирование консолидированной аналитической отчетности о приобретенных финансовых продуктах и финансовой задолженности организаций и группы в целом.

Решение настраивается под IT-архитектуру организаций группы, возможно развитие его функционала в соответствии с требованиями бизнеса.
