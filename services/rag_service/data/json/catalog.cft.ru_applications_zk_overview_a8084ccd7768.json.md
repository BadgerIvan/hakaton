# ЦФТ-Сервис Сьют (CFT-Service Suite)

## Краткое описание

Современные технологии для управления платежами, продуктами и денежной наличностью в различных каналах обслуживания клиентов

## Описание

Современные технологии для управления платежами, продуктами и денежной наличностью в различных каналах обслуживания клиентов, ПО для банкоматов, терминалов и мобильных устройств.

Программное обеспечение, размещенное в Каталоге, **сертифицировано на соответствие стандарту PA DSS**

(данная сертификация проводилась для «Комплекс CFT Service Suitе», в состав которого входит указанное ПО).

Все цены приведены без учета НДС. НДС рассчитывается согласно действующему законодательству РФ. Цены не включают стоимости лицензии на использование ПО третьих лиц (например, СУБД).
