# Контроль исполнения бюджета корпорации

## Краткое описание

Готовое решение для централизованного контроля целевого использования средств Группы компаний

## Описание

Контроль исполнения бюджета корпорации – готовое решение для централизованного контроля целевого использования средств Группы компаний, автоматизирует одну из основных функций единого казначейства.

Возможности:

- Постановка финансовых бюджетов на контроль
- Автоматическое отражение факта исполнения бюджета денежных средств на базе платежных документов на уровне корпорации
- Автоматическое преобразование информации к единой модели аналитических данных с целью получения консолидированной отчетности по корпорации
- Обеспечение оперативного план-факт анализа исполнения бюджетов корпорации.

Решение настраивается под IT-архитектуру организаций группы, возможно развитие его функционала в соответствии с требованиями бизнеса.

Все цены приведены без учета НДС. НДС рассчитывается согласно действующему законодательству РФ. Цены не включают стоимости лицензии на использование ПО третьих лиц (например, СУБД).
