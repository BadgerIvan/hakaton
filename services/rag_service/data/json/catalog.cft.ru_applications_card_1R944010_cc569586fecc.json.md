## Описание

## Поддерживайте актуальную информацию об уровне риска клиента в актуальном состоянии.

Приложение позволяет корректировать критерии риска при выявлении дополнительной информации о клиенте.

## Функциональные возможности

Контроль уровня риска клиента:

- Просмотр данных об уровне, категориях и критериях риска клиента в его карточке
- Корректировка критериев риска клиента для их актуализации
- Возможность получать обновленные данные об уровне и категориях риска после корректировки критериев
- Обновленный уровень риска загружается из ЦФТ-Банк в AML, из AML в ЦФТ-Банк в фоновом режиме
