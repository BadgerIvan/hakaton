# General Ledger + Accounting Engine

## Краткое описание

Решение по автоматизации функций учета построенное на принципе разделения учетного слоя и продуктовых систем

## Описание

ЦФТ-GL + ЦФТ-AE: решение по автоматизации функций учета, построенное по принципу разделения учетного слоя и продуктовых систем. В основе решения лежит механизм преобразования операций продуктового учета в бухгалтерский учет, что обеспечивает быстрый вывод продуктов на рынок по требованию бизнеса, сокращает время на реализацию изменений в требованиях регулятора.

ЦФТ-General Ledger (ЦФТ-GL) – универсальное решение для мульти-фронт/мульти-бэк банка в сервисной архитектуре, обеспечивающее консолидацию главной книги путем объединения бухгалтерской информации из различных систем банка.

ЦФТ-Accounting Engine (ЦФТ-AE) - решение для генерации учета из бизнес-событий систем банка. Бизнес настраивает бизнес-функциональность, изменение требований к учёту не влияют на бизнес.

Все цены приведены без учета НДС. НДС рассчитывается согласно действующему законодательству РФ. Цены не включают стоимости лицензии на использование ПО третьих лиц (например, СУБД).
