## Описание

## Регулируйте максимальные остатки на счетах депозитов при помощи гибкой системы начисления процентов.

Приложение позволяет при расчете процентов по депозитному договору, для суммы остатка, превышающей максимально допустимое значение, использовать процентную ставку, отличную от основной ставки договора. Используя Приложение, банк сможет, с одной стороны - снижать наращивание остатков клиентами после достижения установленных ограничений пониженными процентными ставками на дополнительные взносы, тем самым регулируя свои финансовые риски, либо с другой стороны - стимулировать увеличение остатков существующих договоров повышенными процентными ставками на суммы превышения ограничений, тем самым привлекая более состоятельных клиентов и снижая операционные затраты на обслуживание депозитных договоров.

## Функциональные возможности

- Определение размера лимита для вида депозитного договора, свыше которого проценты рассчитываются по ставке, отличной от основной, в виде:

- Максимально допустимых остатков по счету депозитного договора
- Суммы депозитного договора
- Суммы депозитного договора, кратной заданным коэффициентам

- Определение процентной ставки, применяемой к остатку, превышающему установленный лимит, для вида депозитного договора
- Расчет суммы превышения остатка над установленной величиной лимита
- Расчет процентов на сумму остатка, превышающего установленный лимит, по ставке, отличной от основной, в разрезе отдельных траншей
