## Описание

## Операции по учету сделок покупки и продажи акций по договору ОФБУ, совершенных на биржевых торговых площадках.

Сократите трудозатраты на выполнение потока однотипных операций по сделкам с акциями, совершенным на торговых площадках. Набор процедур Приложения, автоматизируя процессы, позволяет удобно и быстро выполнять задачи формирования бухгалтерских и депозитарных документов по совершенным биржевым сделкам, переоценке, расчету прибыли и вознаграждению управляющему. Также автоматически выполняется расчет стоимости пая учредителя и стоимости чистых активов (СЧА).

## Функциональные возможности

- Ведение договора ОФБУ с реестром учредителей, с историями изменений: стоимости чистых активов ОФБУ, текущей стоимостью пая, настраиваемых тарифных планов для расчета вознаграждений, инвестиционных деклараций
- Бухгалтерский, аналитический и депозитарный учет деятельности по управлению имуществом учредителей
- Отражение операций доверительного управляющего, совершенных банком на ТП, по ОФБУ в бухгалтерском учете банка (главы Б и Д):
  - Ввод учредителя в ОФБУ; ведение истории изменений размера доли учредителя
  - Прием ДС (рубли) учредителя в ОФБУ, автоматический расчет количества паев учредителя
  - Расчет стоимости чистых активов (СЧА) ОФБУ
  - Расчет текущей номинальной стоимости пая
  - Вывод ДС (рубли) учредителя из ОФБУ
  - Расчет и взимание вознаграждения учредителя по тарифной схеме, определенной в договоре, за период и при выводе доли учредителя
  - Сделки покупки/продажи акций , совершенные банком на ТП
  - Ведение портфеля по договору ДУ по учетной политике (FIFO), определенной в договоре ДУ
  - Объединение выпусков ЦБ в портфеле ДУ
  - Переоценка портфеля ДУ по ТСС (ежедневная/по требованию)
  - Получение дивидендов
  - Учет финансового результата по договору ДУ за период
  - Отражение затрат управляющего
  - Учет операций, связанных с торгами на бирже: ввод/вывод ДС на/с торговой площадки, переводы во время торгов и т.д.
  - Журнал аналитического учета по портфелю ДУ
