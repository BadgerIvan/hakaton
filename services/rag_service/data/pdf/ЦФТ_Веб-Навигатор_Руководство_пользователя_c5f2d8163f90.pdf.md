1.3 Монитор коммуникационного канала
Монитор коммуникационного канала текущей сессии запускается из панели
инструментов, либо при вызове операции, которая предполагает запись отладочной
информации в монитор.
В верхней части окна находится панель инструментов, центральная (основная)
часть окна заполняется содержимым текущего коммуникационного канала. В основной
части окна возможно выделение и копирование произвольных фрагментов текста, а
также поиск по тексту. Поиск по тексту осуществляется с помощью окна в верхней части
монитора.

2.2 Сортировка по возрастанию и по убыванию
Сортировка списка экземпляров (по возрастанию или по убыванию)
осуществляется по значению элементов выделенного столбца. Выполнение команды
сортировки приводит к формированию нового запроса к базе данных и обновлению
выборки. Команда сортировки вызывается путем нажатия на кнопку сортировки в
заголовке столбца
Для столбцов типа "Строка" и "Мемо-поле" сортировка в колонках
представлений происходит в алфавитном порядке.
Сортировка по столбцам типа "Логика" происходит по трём значениям: "Нет",
"Да" и "Пусто". При сортировке по возрастанию экземпляры распределяются в
последовательности "Нет", "Да", "Пусто", а при сортировке по убыванию – в обратном
порядке.
Сортировка по столбцам типа "Число" и "Дата" происходит согласно их
числовому значению.
Столбцы типа "Ссылка" и "Массив" сортируются по двум значениям, которые
они могут принимать: "Пусто" и "Не пусто". При сортировке по возрастанию список
начинают экземпляры со значением "Не пусто", затем следуют экземпляры со
значением "Пусто", а при сортировке по убыванию – наоборот.
При выделении нескольких столбцов (см. Выделение ячеек, столбцов в
представлении) 56 сортировка производится в порядке выделения.

2.3 Суммирование по колонкам
Команда выполняет суммирование значений по выделенным колонкам. Результат
выдается в отдельном окне.
Для того, чтобы просуммировать значения в колонке, следует выделить ее
(щелкнув левой кнопкой мыши по заголовку, удерживая нажатой клавишу Ctrl, или
установив курсор в ячейке колонки), а затем вызвать процедуру суммирования.
Если тип колонки поддерживает статистику, то в результате выполнения операции
будут представлены два числа – сумма значений записей в колонке и общее количество
просуммированных записей.
Если тип колонки не поддерживает статистику, в результате выполнения операции
в первом столбце будет содержаться информация обо всех возможных значениях
колонки, а во втором столбце будет указано количество записей, просуммированных в
первом столбце.
Для того, чтобы просуммировать значения в нескольких колонках следует
выделить их и вызвать процедуру суммирования (о выделении нескольких колонок
одновременно см. пункт (3.6 Выделение ячеек, столбцов в представлении 56 ). Если
операцию суммирования поддерживают все типы указанных колонок, то будет
подсчитана сумма для каждой колонки в отдельности, и указано количество записей, по
которым проводилось суммирование.
Если среди указанных колонок будет присутствовать хотя бы один тип, не
поддерживающий статистику, будет проведено суммирование по каждому уникальному
значению несуммируемых колонок в отдельности.

Параметр типа "Дата": при редактировании параметров типа "Дата" можно

соответствующее установленным ограничениям на вводимое значение. Выполнение
операции в этом случае невозможно. Выйти из экранной формы операции можно,
изменив значение на допустимое, или по кнопке "Отмена" без сохранения изменений.
Логический параметр: редактирование логических параметров осуществляется
щелчком левой кнопки мыши или с помощью клавиши Enter (при этом соответствующий
флаг получает значение "Установлен" и заполняется символом, удаление значения
производится аналогичным образом). Для редактирования параметров типа "Вариант"
необходимо активизировать переключатель, соответствующий нужному варианту.

типа параметра операции. Маски ввода определяют формат ввода данных и могут

4.7 Выделение экземпляров в представлениях
Выделение текущей строки
Текущая строка выделяется контрастным цветом. При открытии нового окна
текущей строкой является первая. Для того чтобы выделить (сделать текущей) другую
строку, следует щелкнуть левой кнопкой мыши по необходимой строке.
Выделение строк
Выделить или снять выделение со строки можно щелчком мыши по
соответствующей строке. Выделить все строки или снять выделение можно нажав на
значок на признак выделения на верхней строке представления.
Также, у пользователя присутствует возможность выделить нескольких срок. Для
этого следует щелкнуть левой кнопкой мыши на левом столбце одной из строк (выделить
ее), а затем выделять другие строки, при этом удерживая нажатыми кнопки Shift или
Ctrl.
По клавише Ctrl каждая следующая строка будет выделяться независимо, а по
клавише Shift будут выделены все строки между первой и последней из выделенных.
Выделение экземпляров влияет на запуск операций. При этом следует иметь в
виду, что порядок вызова операций для выделенных экземпляров совпадает с порядком их
выделения.
При наложении фильтра на представление часть выделенных экземпляров может
не удовлетворить условиям фильтра – в этом случае такие экземпляры теряют
выделение.
